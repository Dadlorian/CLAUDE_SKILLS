# Property Management Performance Benchmarks

## Overview
Industry benchmarks for evaluating property management performance across operational, financial, and tenant satisfaction metrics.

## Occupancy Metrics

### Physical Occupancy Rate
**Definition**: Percentage of units with paying tenants

**Benchmarks by Property Class**:
- Class A (Luxury): 95-98%
- Class B (Mid-Range): 93-96%
- Class C (Value): 90-94%
- New Construction (Year 1-2): 85-95% (lease-up phase)

**By Market Type**:
- Primary Markets (NYC, SF, LA): 95-97%
- Secondary Markets: 93-96%
- Tertiary Markets: 90-94%

**Seasonal Variations**:
- Peak Season (Spring/Summer): +2-3% above average
- Slow Season (Winter): -2-3% below average

**Red Flags**:
- Below 90%: Significant operational or market issues
- Below 85%: Critical intervention needed

### Economic Occupancy Rate
**Definition**: Percentage of potential rent being collected

**Benchmark**: 92-95%

**Gap Analysis**:
```
Physical Occupancy: 95%
Economic Occupancy: 92%
Loss-to-Lease: 3% (units leased below market)
```

**By Day**:
```
Day 1 (due date): 75-80%
Day 3 (end of grace): 90-93%
Day 5: 96-98%
Day 10: 98-99%

```

### Delinquency Rate
**Benchmark**: <2% of gross scheduled rent

**By Severity**:
```
1-30 days: 1.5-2.5%
31-60 days: 0.3-0.5%
61-90 days: 0.1-0.2%
90+ days: <0.1%
```

**Red Flags**:
- >3% total delinquency
- >5% requires immediate action
- >10% indicates serious problems

### Bad Debt / Write-Offs
**Benchmark**: <1.5% of gross scheduled rent annually

**Calculation**:
```
Annual GSR: $1,200,000
Target Bad Debt (<1.5%): $18,000
Actual Write-Offs: $24,000
Variance: $6,000 over target (2.0%)
```

### Average Days to Collect
**Benchmark**: 3-5 days from due date

**Analysis**:
```
Total Rent Collected: $100,000
Day 1: $78,000 (78%)
Day 3: $15,000 (15%)
Day 5: $5,000 (5%)
Day 10: $2,000 (2%)

Weighted Average Days:
(78,000×1 + 15,000×3 + 5,000×5 + 2,000×10) / 100,000
= 1.97 days average
```

## Leasing Metrics

### Time to Lease (Days Vacant)
**Benchmark**: 20-30 days

**By Season**:
- Peak (May-Aug): 15-25 days
- Moderate (Sep-Nov, Mar-Apr): 25-35 days
- Slow (Dec-Feb): 30-45 days

**Red Flags**:
- >45 days: Pricing or marketing issue
- >60 days: Serious concerns about unit or market

**By Property Class**:

## Tenant Satisfaction

### Net Promoter Score (NPS)
**Benchmark**: 40-60 for property management

**Scale**:
```
Promoters (9-10): 50-60%
Passives (7-8): 30-40%
Detractors (0-6): 10-20%

NPS = % Promoters - % Detractors
Target: 40-50 (Good), 50+ (Excellent)
```
