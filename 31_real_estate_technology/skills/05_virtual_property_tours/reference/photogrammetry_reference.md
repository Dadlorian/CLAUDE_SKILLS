# Photogrammetry Reference

## Capture Requirements
- 60-80% overlap between photos
- Multiple angles (every 15-30 degrees)
- Consistent lighting
- 100-300 photos for single room
- 500-1000 photos for house

## Processing Software
- **RealityCapture**: Fast, professional
- **Agisoft Metashape**: Industry standard
- **Meshroom**: Free, open-source

## Workflow
1. Capture photos
2. Import to software
3. Align photos (Structure from Motion)
4. Generate point cloud
5. Create mesh
6. Generate texture
7. Export model

## Output Formats
- OBJ: Universal 3D format
- FBX: Game engines
- GLTF/GLB: Web (Three.js)
- USD: Apple/Pixar format
