# VR Platforms Reference

## WebVR Frameworks
- **A-Frame**: HTML-based VR
- **Three.js**: Low-level 3D
- **Babylon.js**: Game engine for web

## A-Frame Example
```html
<a-scene>
  <a-sky src="360-photo.jpg"></a-sky>
  <a-entity
    gltf-model="house.glb"
    position="0 0 -5">
  </a-entity>
</a-scene>
```
