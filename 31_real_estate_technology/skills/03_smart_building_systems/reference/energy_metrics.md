# Energy Metrics Reference

## Key Performance Indicators

### Energy Use Intensity (EUI)
```
EUI = Annual Energy (kBtu) / Building Area (sq ft)
```

**Benchmarks**:
- Office: 80-100 kBtu/sqft/year
- Retail: 100-150
- Hotel: 120-200
- Warehouse: 20-40

### Energy Star Score
- 1-100 scale (median = 50)
- Based on peer buildings
- 75+ eligible for Energy Star certification

### Peak Demand
```
Peak Demand (kW) = Maximum 15-minute average power
```
- Utility demand charges based on peak
- Reduce peaks via load shifting

### Power Factor
```
Power Factor = Real Power / Apparent Power
```
- Target: > 0.95
- Low PF = utility penalties
- Improve with capacitors

## Cost Metrics

### Cost per Square Foot
```
Energy Cost/sqft/year = Annual Energy Cost / Building Area
```

### Cost Avoidance
```
Savings = (Baseline kWh - Actual kWh) × Rate
```

## Carbon Metrics

### Carbon Footprint
```
CO2 (tons) = kWh × Emission Factor
```
- Grid average: 0.92 lbs CO2/kWh
- Natural gas: 117 lbs CO2/therm

### Carbon Intensity
```
kg CO2 / sq ft / year
```

## Monitoring Frequency

- Real-time: Every 15 minutes
- Daily: Aggregated totals
- Monthly: Utility bill reconciliation
- Annual: Benchmarking, goals
