# Underwriting Criteria Reference

## Debt-to-Income Ratio (DTI)
```
DTI = (Total Monthly Debt) / (Gross Monthly Income)

Max DTI:
- Conventional: 43-50%
- FHA: 43% (up to 57% with compensating factors)
- VA: 41%
```

## Credit Score Requirements
| Loan Type | Minimum | Best Rates |
|-----------|---------|------------|
| Conventional | 620 | 740+ |
| FHA | 580 | 640+ |
| VA | 580 | 640+ |
| USDA | 640 | 680+ |
| Jumbo | 700 | 760+ |

## Loan-to-Value (LTV)
```
LTV = (Loan Amount) / (Appraised Value) × 100

Max LTV:
- Conventional: 97% (with PMI)
- FHA: 96.5%
- VA: 100%
- Jumbo: 80%
```

## Income Verification
- W-2s (2 years)
- Pay stubs (recent 30 days)
- Tax returns (2 years)
- Bank statements (2-3 months)

## Asset Verification
- Down payment
- Reserves (2-6 months PITI)
- Seasoned funds (60+ days)

## Appraisal
- Licensed appraiser
- Comparable sales approach
- Value must support loan amount
