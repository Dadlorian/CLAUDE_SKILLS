# Construction Workflows Reference

## Pre-Construction
1. Site surveying
2. Geotechnical investigation
3. Permits and approvals
4. Contract negotiation
5. Mobilization

## Construction Phase
### Foundation
- Excavation
- Footings
- Foundation walls
- Waterproofing

### Framing
- Floor framing
- Wall framing
- Roof framing

### MEP (Rough-In)
- Electrical rough-in
- Plumbing rough-in
- HVAC installation

### Exterior
- Roofing
- Siding
- Windows/doors

### Interior
- Drywall
- Flooring
- Cabinets
- Trim

### Final
- MEP finish
- Painting
- Landscaping
- Final inspection

## Procore Workflow
1. Create project
2. Upload drawings
3. Create RFIs
4. Track daily logs
5. Manage submittals
6. Track punch list
7. Close out
