GRAIN: One row per product per sales transaction line item

KEY RELATIONSHIPS:
- Each fact row references exactly one customer (N:1)
- Each fact row references exactly one product (N:1)
- Each fact row references exactly one store (N:1)
- Each fact row references exactly one date (N:1)
- Each fact row references exactly one promotion (N:1 or may reference "No Promotion")

DIMENSIONAL ATTRIBUTES:
- All dimensions are denormalized (hierarchies embedded)
- All dimensions have surrogate keys (customer_key, product_key, etc.)
- All dimensions have natural business keys (customer_id, product_id, etc.)
- All dimensions use SCD Type 2 for history tracking

FACT TABLE CHARACTERISTICS:
- Narrow table (foreign keys + numeric facts only)
- Degenerate dimensions: transaction_number, line_number
- Additive facts: quantity, extended_price, discount_amount, tax_amount, total_amount
- No NULL foreign keys (use "Unknown" dimension members)
