# Dashboard Templates

## Executive Dashboard Template

### Layout
```
┌─────────────────────────────────────────────────────┐
│ Company Logo         Executive Dashboard     [Filter]│
├──────────┬──────────┬──────────┬──────────────────────┤
│ Revenue  │ Profit   │ Orders   │ Customers            │
│ $2.4M    │ $480K    │ 1,234    │ 567                  │
│ ↑ 15%    │ ↑ 20%    │ ↑ 8%     │ ↑ 12%                │
├──────────┴──────────┴──────────┴──────────────────────┤
│ Revenue Trend (Last 12 Months)                        │
│ [Line Chart]                                          │
├──────────────────────┬───────────────────────────────┤
│ Top 5 Products       │ Regional Performance          │
│ [Bar Chart]          │ [Map]                         │
└──────────────────────┴───────────────────────────────┘
```

### Key Features
- 4-6 KPI cards at top
- Trend visualization (12 months)
- Top performers
- Geographic breakdown
- Single-page view
- Minimal interactivity

## Operational Dashboard Template

### Layout
```
┌─────────────────────────────────────────────────────┐
│ Filters: [Date] [Region] [Status] [Category]        │
├──────────┬──────────┬──────────┬──────────────────────┤
│ Today    │ This Week│ This Month│ YTD                 │
│ 125      │ 890      │ 3,450     │ 42,100              │
├──────────┴──────────┴──────────┴──────────────────────┤
│ Today's Activity (Live Updates)                       │
│ [Real-time Chart]                                     │
├───────────────────────────────────────────────────────┤
│ Detailed Transactions                                 │
│ [Sortable, Filterable Table]                         │
│ [Export to Excel]                                    │
└───────────────────────────────────────────────────────┘
```

### Key Features
- Multiple time periods
- Real-time or frequent refresh
- Detailed data table
- Export capability
- Multiple filters
- Drill-down enabled

## Analytical Dashboard Template

### Layout
```
┌─────────────────────────────────────────────────────┐
│ Analysis Controls                                    │
│ Metric: [Dropdown] Dimension: [Dropdown] View: [Tab]│
├──────────────────────┬───────────────────────────────┤
│ Trend Analysis       │ Distribution                  │
│ [Line/Area Chart]    │ [Histogram]                   │
├──────────────────────┼───────────────────────────────┤
│ Correlation          │ Cohort Analysis               │
│ [Scatter Plot]       │ [Heatmap]                     │
├──────────────────────┴───────────────────────────────┤
│ Supporting Metrics and Details                       │
└───────────────────────────────────────────────────────┘
```

### Key Features
- Dynamic metric selection
- Multiple analysis types
- Statistical visualizations
- Correlation analysis
- Advanced filtering
- Data exploration focus
