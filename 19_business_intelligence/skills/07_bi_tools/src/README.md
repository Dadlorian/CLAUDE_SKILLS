# BI Tools Source Examples

This directory contains practical code examples, templates, and configurations for major BI platforms.

## Directory Structure

- `tableau/` - Tableau workbook XML structures, calculations, and scripts
- `powerbi/` - Power BI DAX measures, Power Query M code, and templates
- `looker/` - LookML models, views, and dashboard definitions
- `qlik/` - Qlik Sense load scripts, set analysis expressions, and app structures
- `superset/` - Apache Superset configurations, SQL queries, and dashboard JSON
- `common/` - Platform-agnostic SQL, Python scripts, and utilities

## Usage

These examples are meant as references and starting points. Adapt them to your specific use cases and data models.

All examples assume you have:
- Appropriate platform access and permissions
- Basic understanding of the platform
- Sample data matching the structure shown

## Contributing

When adding new examples:
1. Include clear comments explaining the purpose
2. Use realistic but generic naming
3. Document any prerequisites or dependencies
4. Follow the existing file naming convention
