# User Onboarding Workflow Guide

## 5-Day Onboarding Journey

### Day 1: Welcome & Access
```yaml
Automated:
  1. Trigger on hire date (HR system)
  2. Create accounts:
     - Data catalog
     - BI tool
     - Slack channels
  3. Send welcome email:
     Subject: Welcome to Data Analytics! 🎉
     - Access links
     - Getting started video (5 min)
     - First assignment
     - Support contacts

Manual:
  - Manager introduces to team champion
  - Add to department Slack channel
```

### Day 2: Exploration
```yaml
Self-Paced:
  - Watch "Data Catalog Tour" (10 min)
  - Complete scavenger hunt:
    □ Find customer orders table
    □ Check data quality score
    □ Identify table owner
    □ Preview sample data
  - Join #data-questions Slack

Assignment:
  "Find 3 datasets relevant to your role"
```

### Day 3: First Dashboard
```yaml
Guided Activity:
  - Watch "Dashboard Basics" (15 min)
  - Follow tutorial:
    1. Open Sales Dashboard
    2. Apply filters
    3. Drill down into details
    4. Export chart
    5. Schedule email report

Practice:
  "Explore your department's dashboard"
```

### Day 4: Hands-On
```yaml
Workshop (Optional, 1 hour):
  - Live session with trainer
  - Create simple dashboard
  - Q&A
  - Peer networking

Alternatives:
  - Self-paced video series
  - 1:1 with champion
  - Office hours drop-in
```

### Day 5: Certification
```yaml
Assessment:
  - 10-question quiz
  - Practical exercise
  - 80% to pass

On Pass:
  - Level 1 Certified badge
  - Full tool access
  - Listed in directory
  - Swag sent

On Fail:
  - Retake available
  - Offer 1:1 help
  - No penalty
```

## Onboarding Checklist

```yaml
Pre-Day 1:
  □ HR system integration active
  □ Welcome email template ready
  □ Accounts auto-provisioned
  □ Training videos current

Day 1:
  □ Welcome email sent
  □ Access verified
  □ Manager notified
  □ Champion assigned

Days 2-4:
  □ Progress tracked
  □ Reminders sent if stalled
  □ Help offered proactively
  □ Engagement monitored

Day 5:
  □ Assessment completed
  □ Certification awarded
  □ Badge issued
  □ Follow-up scheduled (30 days)
```

## Tracking & Optimization

```yaml
Metrics to Monitor:
  - Day 1 completion rate (Target: >90%)
  - Day 5 certification rate (Target: >80%)
  - Time to complete (Target: 5 days)
```
