# Training Program Setup Guide

## 30-Day Training Program Launch

### Week 1: Curriculum Development

```yaml
Identify Personas:
  - Executives (dashboard viewers)
  - Managers (dashboard creators)
  - Analysts (power users)
  - Business users (self-service)

Create Learning Paths:
  Level 1 - Data Consumer (2 hours):
    - Finding data in catalog (30 min)
    - Reading dashboards (45 min)
    - Basic filters (30 min)
    - Getting help (15 min)

  Level 2 - Data Explorer (8 hours):
    - SQL basics (3 hours)
    - Dashboard creation (2 hours)
    - Joins and aggregations (2 hours)
    - Best practices (1 hour)

  Level 3 - Data Analyst (16 hours):
    - Advanced SQL (4 hours)
    - Analytics methodologies (4 hours)
    - Metric creation (4 hours)
    - Performance optimization (4 hours)
```

### Week 2: Content Creation

```yaml
Video Production:
  - Screen recordings with narration
  - 5-10 minutes per video
  - Focus on specific tasks
  - Include captions

Tools Needed:
  - Loom or Camtasia
  - Good microphone
  - Quiet recording space
  - Editing software

Example Videos:
  1. "Your First Catalog Search"
  2. "Understanding Dashboard Filters"
  3. "Writing Your First SQL Query"
  4. "Creating a Simple Dashboard"
  5. "Joining Two Tables"
```

### Week 3: Platform Setup

```yaml
Learning Platform Options:

DIY (Free):
  - YouTube playlist (unlisted)
  - Confluence/Notion pages
  - Google Drive folder
  - Pros: Free, simple
  - Cons: No tracking, basic

LMS (Paid):
  - Lessonly ($10k+/year)
  - TalentLMS ($5k+/year)
  - Pros: Tracking, assessments, slick
  - Cons: Cost, setup time

Hybrid (Recommended):
  - Videos on YouTube
  - Exercises in shared doc
  - Quizzes in Google Forms
  - Tracking in spreadsheet
  - Cost: Free
  - Effort: Medium
```

## Training Best Practices

```yaml
Make it Practical:
  - Real company data (anonymized)
  - Actual use cases
  - Hands-on exercises
  - Build real dashboards

Keep it Short:
  - 5-10 min videos max
  - One concept per video
  - Bite-sized learning
  - Easy to rewatch

Provide Support:
  - Office hours
  - Slack channel
  - FAQ document
  - 1:1 help available

Track Progress:
  - Completion rates
  - Quiz scores
  - Certification earned
  - Tool usage correlation
```
