## Overview

This domain provides comprehensive, production-grade software engineering expertise across the entire development lifecycle. From designing scalable architectures to implementing secure APIs, from building performant frontends to optimizing database queries, this skill set covers everything modern software engineers need to build world-class applications.

### What This Domain Covers

- **Backend Development**: Microservices, APIs, databases, caching, message queues, authentication
- **Frontend Development**: Modern frameworks, state management, performance, accessibility, testing
- **Full-Stack Development**: Monorepo management, SSR/SSG, real-time features, authentication flows
- **Software Architecture**: Design patterns, architectural patterns, system design, cloud-native patterns
- **DevOps Practices**: CI/CD, containerization, orchestration, infrastructure as code
- **Security Engineering**: Application security, dependency management, secrets management
- **Testing Strategies**: Test pyramid, TDD/BDD, contract testing, performance testing
- **Performance Engineering**: Backend optimization, frontend performance, monitoring, profiling
- **API Design**: REST, GraphQL, gRPC, event-driven APIs, API documentation
- **System Design**: Scalability, distributed systems, resilience patterns, observability

## Best Practices Emphasized

### Code Quality
1. **SOLID Principles**: Single Responsibility, Open/Closed, Liskov Substitution, Interface Segregation, Dependency Inversion
2. **DRY (Don't Repeat Yourself)**: Eliminate code duplication
3. **KISS (Keep It Simple, Stupid)**: Favor simplicity over complexity
4. **YAGNI (You Aren't Gonna Need It)**: Don't add functionality until needed
5. **Clean Code**: Meaningful names, small functions, clear intent

### Architecture
1. **Twelve-Factor App**: Methodology for cloud-native applications
2. **Microservices Best Practices**: Service independence, API contracts, fault tolerance
3. **Domain-Driven Design**: Bounded contexts, ubiquitous language, aggregates
4. **Event-Driven Architecture**: Loose coupling, eventual consistency, event sourcing

### Security
1. **OWASP Top 10**: Protection against common vulnerabilities
2. **Principle of Least Privilege**: Minimal access rights
3. **Defense in Depth**: Multiple layers of security
4. **Zero Trust**: Never trust, always verify

### Performance
1. **Database Optimization**: Proper indexing, query optimization, connection pooling
2. **Caching Strategy**: Multi-layer caching (CDN, application, database)
3. **Async Operations**: Non-blocking I/O, async/await patterns
4. **Resource Management**: Connection pools, memory management, garbage collection

### Testing
1. **Test Pyramid**: More unit tests, fewer E2E tests
2. **Test Coverage**: Aim for 80%+ coverage on critical paths
3. **Fast Feedback**: Keep test suites fast
4. **Continuous Testing**: Automated tests in CI/CD pipeline

## Common Workflows

### Feature Development Workflow
1. **Requirements Analysis**: Understand what needs to be built
2. **Design**: Create technical design, consider edge cases
3. **Implementation**: Write code following TDD
4. **Code Review**: Peer review for quality and security
5. **Testing**: Comprehensive test suite
6. **Documentation**: Update docs and comments
7. **Deployment**: CI/CD pipeline with monitoring
8. **Monitoring**: Track metrics and errors

### Bug Fix Workflow
1. **Reproduction**: Reliably reproduce the bug
2. **Root Cause Analysis**: Find the underlying cause
3. **Fix Design**: Plan the fix, consider side effects
4. **Implementation**: Write the fix with tests
5. **Regression Testing**: Ensure no new issues
6. **Code Review**: Get peer review
7. **Deployment**: Deploy with monitoring
8. **Verification**: Confirm fix in production

### Refactoring Workflow
1. **Identify**: Find code smells or technical debt
2. **Tests**: Ensure comprehensive test coverage
3. **Small Steps**: Refactor in small, safe increments
4. **Continuous Testing**: Run tests after each change
5. **Code Review**: Get feedback on improvements
6. **Documentation**: Update relevant documentation
7. **Monitoring**: Watch for performance regressions

## Troubleshooting

### Common Issues

**Problem**: "My API is slow"
- Check database queries (N+1 problem, missing indexes)
- Add caching layers
- Profile the application
- Check for blocking operations
- Review network latency

**Problem**: "Frontend bundle is too large"
- Implement code splitting
- Remove unused dependencies
- Use tree shaking
- Lazy load components
- Analyze bundle with webpack-bundle-analyzer

**Problem**: "Authentication keeps failing"
- Check token expiration
- Verify CORS configuration
- Review secret key management
- Check for clock skew in distributed systems
- Validate JWT signature algorithm

**Problem**: "Deployment pipeline failing"
- Check test failures
- Review linting errors
- Verify environment variables
- Check Docker build context
- Review CI/CD logs
