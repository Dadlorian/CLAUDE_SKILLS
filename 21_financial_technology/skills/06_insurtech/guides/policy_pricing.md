# Insurance Policy Pricing Guide

## Pricing Strategy

### Pricing Objectives
1. Cover expected claims and expenses
2. Maintain profit margin (10-20%)
3. Remain competitive
4. Manage risk exposure
5. Support growth objectives

### Pricing Approach
```
Pure Premium = Expected Claims + Loading
             = (Frequency × Severity) + Loading
```

## Rate Change Management

### Approval Process
```
1. Actuarial Analysis
   └─ Loss ratio analysis

2. Rate Filing
   ├─ Gather historical data
   ├─ Calculate indicated change
   ├─ Prepare justification
   └─ File with regulator

3. Regulatory Review
   ├─ Regulator examines
   ├─ May ask questions
   ├─ May deny or approve
   └─ Timeline: 30-60 days

4. Implementation
   ├─ Schedule effective date
   ├─ Communicate to customers
   ├─ Update systems
   └─ Monitor results

5. Monitoring
   ├─ Track loss ratios
   ├─ Monitor competitiveness
   ├─ Assess customer impact
   └─ Plan next adjustment
```

### Rate Adjustment Example
```
Current: $1,000 premium, 70% loss ratio
Target: 65% loss ratio
Required Rate Change = (70% - 65%) / 70% = 7.1% increase

File for 7% increase
If approved: New premium = $1,070
Expected loss ratio: 65%
Expected profit: 35%
```

## Profitability Analysis

### Combined Ratio
```
Formula:
Loss Ratio + Expense Ratio = Combined Ratio

Example:
Loss Ratio: 65%
Expense Ratio: 25%
Combined Ratio: 90%
Profit: 10%
```

### Profitability by Segment
```
Analyze:
├─ Loss ratio by product
├─ Loss ratio by region
├─ Loss ratio by channel
├─ Loss ratio by segment
└─ Identify profitable/unprofitable

Actions:
├─ Raise rates for unprofitable
├─ Increase volume for profitable
├─ Exit unprofitable segments
├─ Optimize mix
└─ Focus on growth in profitable
```
