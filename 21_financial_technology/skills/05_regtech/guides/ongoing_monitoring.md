# Ongoing Customer Monitoring Implementation Guide

## Overview

Ongoing monitoring continuously reviews customer activity to identify changes in risk profile or suspicious patterns.

## Monitoring Scope

**Customer Profile Changes:**
- Address changes (new country)
- Beneficial ownership updates
- Employment changes
- Business type changes
- Financial capacity changes
- PEP status changes

**Transaction Monitoring:**
- Transaction amounts vs. baseline
- Geographic changes
- Transaction type changes
- Frequency changes
- Velocity patterns
- Counterparty changes

**Risk Factors:**
- Regulatory announcements
- Adverse media
- Sanctions list matches
- Negative news
- Regulatory violations
- Significant audit findings

## Monitoring Frequency

**Low-Risk Customers:**
- Annual review minimum
- Transaction monitoring continuous
- Sanctions screening continuous

**Medium-Risk Customers:**
- Semi-annual review
- Enhanced transaction monitoring
- Quarterly sanctions screening
- Periodic PEP verification

**High-Risk Customers:**
- Quarterly review (at minimum)
- Real-time transaction monitoring
- Weekly sanctions screening
- Monthly PEP verification
- Enhanced background monitoring

## Monitoring Procedures

**Automated Monitoring:**
- Transaction rules evaluation
- Threshold breach detection
- Pattern anomaly detection
- Sanctions list matching
- PEP status verification
- Adverse media alerts

**Manual Review:**
- Customer profile updates
- Risk score recalculation
- Documentation verification
- Customer communication (if needed)
- Enhanced due diligence (if needed)

## Risk Reassessment

**Triggers for Reassessment:**
- Significant transaction change (> 50%)
- Geographic change (new country)
- Beneficial ownership change
- Customer information change
- Regulatory event
- Adverse media mention
- Customer request
- Periodic reassessment (annual)

**Reassessment Process:**
1. Review customer profile
2. Evaluate new information
3. Recalculate risk score
4. Determine if actions needed
5. Update records
6. Document findings

## Monitoring Effectiveness Metrics

- Reassessment completion rate
- Risk score changes identified
- Account closure rate (high-risk)
- Enhanced CDD triggers
- Transaction pattern changes detected
- Regulatory violations detected

## Best Practices

1. **Continuous Review** - Real-time monitoring
2. **Systematic Approach** - Documented procedures
3. **Regular Updates** - Customer information current
4. **Risk Adjustment** - Dynamic risk assessment
5. **Documentation** - Complete audit trail
6. **Escalation** - Clear procedures for issues
7. **Regulatory Alignment** - Follow guidance

## Regulatory Requirements

- FATF Recommendation: Ongoing monitoring
- Risk-based monitoring frequency
- Customer information updates
- Documented monitoring procedures
- Records of findings and actions
- Regular reassessment timeline
