# Scenario Analysis Guide

## Setting Up Scenarios

### 1. Historical Scenarios
```
2008 Financial Crisis:
- Equities: -48%
- Credit spreads: +300-600 bps
- VIX: 88
- USD: +5%
- House prices: -35%

Apply to portfolio:
- Equities: 20% × -48% = -9.6%
- Credit: 35% × (spread impact -2%) = -0.7%
- Housing: 10% × -35% = -3.5%
Total: -13.8%
```

### 2. Hypothetical Scenarios
```
Scenario: Strong growth, Fed hikes 300 bps
- Equities: +15% (earnings growth)
- Bonds: -10% (duration loss)
- Credit spreads: -50 bps (tighten)
- Cash: +0% (benefit from higher rates)

Scenario: Recession, Fed cuts 200 bps
- Equities: -25% (earnings decline)
- Bonds: +5% (flight to safety)
- Credit spreads: +200 bps (widen)
- Cash: 0%
```

### 3. Multi-factor Analysis
```
Use scenario matrix:
- Interest rates: Down, Stable, Up
- Equities: Down, Stable, Up
- Credit spreads: Tight, Stable, Wide

9 scenarios × correlation assumptions = comprehensive testing
```

## Implementation
- Select 3-5 key scenarios
- Apply quarterly
- Monitor which scenarios most impactful
- Use for capital planning
