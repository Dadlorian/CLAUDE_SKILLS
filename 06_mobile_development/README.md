### Quick Start Examples

#### iOS (SwiftUI)
```swift
import SwiftUI

struct ContentView: View {
    @State private var count = 0

    var body: some View {
        VStack(spacing: 20) {
            Text("Count: \(count)")
                .font(.largeTitle)

            Button("Increment") {
                count += 1
            }
            .buttonStyle(.borderedProminent)
        }
        .padding()
    }
}
```

#### Android (Jetpack Compose)
```kotlin
@Composable
fun CounterScreen() {
    var count by remember { mutableStateOf(0) }

    Column(
        modifier = Modifier
            .fillMaxSize()
            .padding(16.dp),
        verticalArrangement = Arrangement.Center,
        horizontalAlignment = Alignment.CenterHorizontally
    ) {
        Text(
            text = "Count: $count",
            style = MaterialTheme.typography.headlineLarge
        )

        Spacer(modifier = Modifier.height(16.dp))

        Button(onClick = { count++ }) {
            Text("Increment")
        }
    }
}
```

#### React Native
```javascript
import React, { useState } from 'react';
import { View, Text, Button, StyleSheet } from 'react-native';

export default function CounterScreen() {
  const [count, setCount] = useState(0);

  return (
    <View style={styles.container}>
      <Text style={styles.text}>Count: {count}</Text>
      <Button
        title="Increment"
        onPress={() => setCount(count + 1)}
      />
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    justifyContent: 'center',
    alignItems: 'center',
    padding: 16,
  },
  text: {
    fontSize: 32,
    marginBottom: 16,
  },
});
```

#### Flutter
```dart
import 'package:flutter/material.dart';

class CounterScreen extends StatefulWidget {
  @override
  _CounterScreenState createState() => _CounterScreenState();
}

class _CounterScreenState extends State<CounterScreen> {
  int count = 0;

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            Text(
              'Count: $count',
              style: Theme.of(context).textTheme.headlineLarge,
            ),
            SizedBox(height: 16),
            ElevatedButton(
              onPressed: () => setState(() => count++),
              child: Text('Increment'),
            ),
          ],
        ),
      ),
    );
  }
}
```

## Common Challenges & Solutions

### Challenge 1: Platform Fragmentation
**Problem**: Supporting multiple OS versions and device sizes
**Solution**:
- Target last 2 major OS versions (iOS 16+, Android 12+)
- Use platform abstractions and responsive layouts
- Test on representative device matrix (small phone, large phone, tablet)

### Challenge 2: Performance Issues
**Problem**: Slow app startup, janky animations, memory leaks
**Solution**:
- Profile early and often with platform tools
- Implement lazy loading and code splitting
- Use platform-specific optimizations (Baseline Profiles on Android, dylib preloading on iOS)
- Monitor with Firebase Performance or similar

### Challenge 3: Testing Complexity
**Problem**: Too slow to test on real devices, emulators miss edge cases
**Solution**:
- Implement testing pyramid (70% unit, 20% integration, 10% E2E)
- Use cloud device farms for critical paths
- Automate tests in CI/CD pipeline
- Mock external dependencies for faster unit tests

### Challenge 4: Security Vulnerabilities
**Problem**: Data breaches, MITM attacks, reverse engineering
**Solution**:
- Follow OWASP Mobile Security Testing Guide
- Implement certificate pinning for critical APIs
- Use platform secure storage (Keychain/Keystore)
- Regular security audits and penetration testing

### Challenge 5: Cross-Platform Code Sharing
**Problem**: Need iOS and Android apps but limited resources
**Solution**:
- Evaluate React Native or Flutter for greenfield projects
- Consider native with shared business logic (Kotlin Multiplatform)
- Use web views for content-heavy sections
- Prioritize one platform based on target audience, then expand
