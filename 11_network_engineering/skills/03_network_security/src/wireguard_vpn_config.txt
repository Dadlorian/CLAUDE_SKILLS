# =====================================
# Installation & Setup (Linux)
# =====================================

# Install WireGuard:
# apt-get install wireguard wireguard-tools
# OR
# yum install wireguard-tools

# Generate keys:
# umask 077
# wg genkey | tee server_private.key | wg pubkey > server_public.key
# wg genkey | tee client_private.key | wg pubkey > client_public.key

# Save configuration to /etc/wireguard/wg0.conf
# Set permissions:
# chmod 600 /etc/wireguard/wg0.conf

# Enable and start:
# systemctl enable wg-quick@wg0
# systemctl start wg-quick@wg0

# Verify status:
# wg show
# ip addr show wg0

# =====================================
# Security Best Practices
# =====================================

# 1. Key Generation:
#    - Use strong random source
#    - Generate new keys for each deployment
#    - Store private keys securely

# 2. Key Rotation:
#    - Rotate keys annually
#    - Update all peers simultaneously
#    - Maintain backward compatibility during rotation

# 3. Network Design:
#    - Use isolated address space (10.255.0.0/16)
#    - Don't overlap with existing networks
#    - Use small subnets for clients (/32)

# 4. Firewall Integration:
#    - Allow only necessary ports (51820/UDP default)
#    - Change port if behind restrictive firewall
#    - Implement rate limiting

# 5. Monitoring:
#    - Monitor peer activity
#    - Log connections
#    - Alert on disconnections
#    - Track bandwidth usage

# 6. Resilience:
#    - Configure multiple servers
#    - Use DNS round-robin
#    - Test failover scenarios

# =====================================
# Troubleshooting
# =====================================

# Issue: Connection refused
# Diagnosis:
#   - wg show (check if interface active)
#   - ufw status (check firewall)
#   - netstat -ulnp | grep 51820 (verify port open)
# Solution:
#   - Verify port is open
#   - Check firewall rules
#   - Restart WireGuard

# Issue: Slow performance
# Diagnosis:
#   - Monitor bandwidth usage
#   - Check system load
#   - Verify MTU size
# Solution:
#   - Optimize MTU (usually 1420)
#   - Enable hardware acceleration
#   - Check for bottlenecks

# Issue: Intermittent disconnections
# Diagnosis:
#   - Check network stability
#   - Review logs
#   - Monitor keepalive settings
# Solution:
#   - Increase PersistentKeepalive
#   - Improve network stability
#   - Monitor peer status
