! ===================== DEPLOYMENT & TESTING =====================

1. Deploy certificate
2. Configure portal and gateways
3. Set authentication (LDAP)
4. Enable MFA (Okta)
5. Configure device compliance
6. Test with pilot users
7. Monitor logs and performance
8. Gradual rollout to all users

! ===================== CLIENT INSTALLATION =====================

Windows:
  1. Download from https://paloaltonetworks.com
  2. Run PanGPClient-x.x.x-Setup.exe
  3. Complete installation wizard
  4. Restart computer
  5. Launch GlobalProtect app
  6. Connect to vpn.company.com

macOS:
  1. Download PanGP Client-x.x.x.dmg
  2. Open DMG file
  3. Drag app to Applications folder
  4. Launch GlobalProtect
  5. Connect to vpn.company.com

iOS/Android:
  1. Download from App Store/Google Play
  2. Open Palo Alto Networks app
  3. Add portal: vpn.company.com
  4. Authenticate with credentials
  5. Connect
