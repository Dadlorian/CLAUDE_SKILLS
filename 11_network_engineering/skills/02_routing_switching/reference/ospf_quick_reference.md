# OSPF Quick Reference Guide

## Protocol Basics

- **Protocol Type:** Interior Gateway Protocol (IGP), Link-State
- **Algorithm:** Dijkstra Shortest Path First (SPF)
- **Administrative Distance:** 110
- **Authentication Methods:** Plain-text, MD5, SHA-256
- **Metric:** Cost (Bandwidth-based, default 100Mbps/interface-bandwidth)
- **Multicast Address:** 224.0.0.5 (AllSPFRouters), 224.0.0.6 (AllDRRouters)
- **Process ID:** Locally significant (1-65535)
- **Hello/Dead Timer Defaults:** 10 seconds/40 seconds (broadcast), 30/120 (NBMA)

## OSPF Areas

| Area Type | Loop Prevention | Default Route | External Routes |
|-----------|-----------------|----------------|-----------------|
| Backbone (0) | N/A | N/A | Yes |
| Standard | SPF flooding | Imported by ABR | Yes |
| Stub | SPF flooding | Default by ABR | No (except ASBR) |
| Totally Stubby | SPF flooding | Default by ABR | No |
| NSSA | SPF flooding | Default by ASBR | Type-7 converted to Type-5 by ABR |

## Router Types

- **IR (Internal Router):** All interfaces in single area
- **ABR (Area Border Router):** Interfaces in multiple areas
- **ASBR (Autonomous System Border Router):** Redistributes external routes
- **DR (Designated Router):** On each broadcast/NBMA segment
- **BDR (Backup Designated Router):** Hot standby for DR
- **DROther:** Non-DR/BDR router on segment

## Cost Calculation

```
Interface Cost = 100,000,000 / Bandwidth (in bps)

Examples:
- 10Gbps:     1
- 1Gbps:      1
- 100Mbps:    1
- 10Mbps:     10
- 1Mbps:      100
- Default for higher speeds: 1 (adjust with cost command)
```

## OSPF Timers

| Timer | Default (Broadcast) | Default (NBMA) | Purpose |
|-------|---------------------|-----------------|---------|
| Hello | 10 seconds | 30 seconds | Neighbor discovery |
| Dead | 40 seconds | 120 seconds | Neighbor failure detection |
| Retransmit | 5 seconds | 40 seconds | LSA retransmission |
| LSA Group Pacing | 240 seconds | - | LSA origination pacing |
| SPF Delay | 50ms | - | First SPF calculation |
| SPF Hold Time | 200ms | - | SPF recalculation delay |

## Authentication

### Plain-text Authentication
```
Area 0 authentication enabled, password visible in config
```

### MD5 Authentication
```
HMAC-MD5 with key ID and key
Multiple keys supported for key rollover
```

### SHA Authentication
```
HMAC-SHA-256 (OSPF for IPv6)
HMAC-SHA-1, SHA-256, SHA-384, SHA-512 (RFC 5709)
```

## Metric Manipulation

| Method | Impact | Use Case |
|--------|--------|----------|
| Cost | Per-interface | Link preference |
| Priority | DR election | Force specific DR |
| Auto-cost reference-bandwidth | Global | Normalizing fast links |
| Network prefix cost | Summary route | Controlling ABR summary |

## Convergence Timers

- **SPF Delay:** Time before running first SPF (default 50ms)
- **SPF Hold Time:** Minimum time between consecutive SPF runs (default 200ms)
- **Throttle SPF:** milliseconds argument for maximum SPF hold time
- **Timers lsa arrival:** Minimum milliseconds between arrival of same LSA instance

## Filtering and Redistribution

```
route-map for redistribution control
access-list for prefix filtering
distribute-list for inbound/outbound filtering
ip ospf name-lookup for DNS name resolution in OSPF database
```

## Virtual Links

- **Use Case:** Connect non-backbone area to backbone
- **Requirements:** Transit area ABR to far-side ABR
- **Timers:** Same as standard area
- **Bandwidth:** No bandwidth parameter
- **Authentication:** Same authentication as transit area

## Best Practices

1. Keep hello/dead timers consistent across links
2. Use reference-bandwidth to normalize metric calculation
3. Use DR/BDR on all broadcast networks (priority 0 on unnecessary routers)
4. Filter external routes at ABR level (route redistribution)
5. Use MD5 authentication for security
6. Monitor SPF calculation times on large networks
7. Use multi-area OSPF for networks > 50 routers
8. Implement graceful restart for non-disruptive upgrades
