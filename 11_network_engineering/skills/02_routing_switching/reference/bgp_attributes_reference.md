# BGP Attributes Quick Reference

## Attribute Classification

### Well-Known Mandatory
- **Must be present** in every BGP update
- **Recognized** by all BGP implementations
- **Transitive** across AS boundaries

| Attribute | Purpose | Range | Default |
|-----------|---------|-------|---------|
| Origin | Route source | IGP, EGP, Incomplete | N/A |
| AS_Path | AS traversal | AS sequence | N/A |
| Next_Hop | Next hop address | IP address | N/A |

### Well-Known Discretionary
- **Optional** presence in updates
- **Recognized** by all BGP implementations
- **Transitive** across AS boundaries

| Attribute | Purpose | Scope | Default |
|-----------|---------|-------|---------|
| Local_Preference | Exit point preference | iBGP only | 100 |
| Atomic_Aggregate | Suppressed subpaths | Both | N/A |

### Optional Transitive
- **Optional** presence in updates
- **Recognized** by some implementations
- **Transitive** across AS boundaries (even if not recognized)

| Attribute | Purpose | Usage |
|-----------|---------|-------|
| Aggregator | Aggregation info | Route aggregation |
| Communities | Route grouping | Filtering, policy |
| Originator_ID | RR originator | Route reflection |
| Cluster_List | RR cluster path | Route reflection |

### Optional Non-Transitive
- **Optional** presence in updates
- **Not propagated** if not recognized
- **Non-transitive** across AS boundaries

| Attribute | Purpose | Scope | Match |
|-----------|---------|-------|-------|
| Multi_Exit_Disc (MED) | Entry point cost | eBGP | Same AS |
| Extended Communities | Enhanced grouping | Both | Various |
| Connector | BGP-LS connector | N/A | N/A |

## Origin Attribute

| Value | Type | Source |
|-------|------|--------|
| IGP (0) | Interior | network/aggregate command |
| EGP (1) | Exterior | redistribute (legacy) |
| Incomplete (2) | Unknown | redistribute or aggregation |

## AS_Path Attribute

### AS_Path Structure
- **Sequence:** `65001 65002 65003` (ordered path)
- **Set:** `{65001 65002}` (unordered, from confederation)

### AS_Path Manipulation
```
! Prepend local AS (increase path length)
route-map prepend-as
  set as-path prepend 65000

! Prepend multiple times
set as-path prepend 65000 65000 65000

! Remove private AS
neighbor 10.0.0.1 remove-private-as
```

### AS_Path Filtering
```
! Deny routes from specific AS
ip as-path access-list 1 deny _65000_
ip as-path access-list 1 permit .*

! Route-map example
route-map filter-as out
  match as-path 1
  deny

! Deny customers' customers
ip as-path access-list 2 deny _65001_65002_65003_
```

## Local_Preference Attribute

- **Range:** 0-4294967295 (32-bit)
- **Default:** 100
- **Scope:** iBGP only (not sent to eBGP)
- **Direction:** Higher preferred
- **Use:** Exit point selection

```
! Set local preference in inbound route-map
route-map prefer-path in
  set local-preference 150

! Remove local preference (resets to default 100)
route-map reset-lp
  set local-preference 100
```

## Multi-Exit Discriminator (MED)

- **Range:** 0-4294967295 (32-bit)
- **Default:** 0 (lower preferred)
- **Scope:** eBGP only (sent but comparison limited)
- **Comparison:** Same source AS only
- **Use:** Entry point optimization

```
! Set MED in outbound route-map
route-map set-med out
  set metric 100

! Always compare MED (ignores AS)
bgp always-compare-med

! Deterministic MED
bgp deterministic-med

! MED from tagged community
set extcommunity cost 65000:100
```

## Communities Attribute

### Standard Communities (4-byte)
- **Format:** `AS:value` or well-known names
- **Range:** 0:0 to 65535:4294967295
- **Well-known:**
  - `no-export` (65535:65281) - not exported to eBGP
  - `no-advertise` (65535:65282) - not advertised to anyone
  - `local-as` (65535:65283) - not exported outside confederation

```
! Set community
set community 65000:100

! Multiple communities
set community 65000:100 65000:200

! Add to existing community
set community 65000:100 additive

! Match community
match community 65000:100
```

### Extended Communities (8-byte)
- **Format:** `type:value`
- **Common types:**
  - **RT (Route Target):** For VPN route filtering
  - **ST (Site Target):** For site community
  - **SoO (Site of Origin):** For loop prevention

```
! Set extended community
set extcommunity rt 65000:100

! VPN route target
set extcommunity rt 65000:100 additive

! Cost community
set extcommunity cost 65000:100
```

## Originator_ID Attribute

- **Size:** 32-bit (IP address format)
- **Generated by:** Route Reflector
- **Purpose:** Prevent RR loops
- **Value:** BGP router-id of originating router

```
! RR originator (auto-set)
route-reflector-client

! View originator
show ip bgp 10.0.0.0/24
```

## Cluster_List Attribute

- **Elements:** Cluster IDs
- **Purpose:** Prevent cluster loops
- **Update:** Prepend cluster ID when advertising

```
! Set cluster ID
bgp cluster-id 192.168.1.1

! View cluster list
show ip bgp 10.0.0.0/24 | include Cluster
```

## Atomic_Aggregate Attribute

- **Purpose:** Suppress subpaths from aggregation
- **Generated by:** ASBR performing aggregation
- **Meaning:** Some routes are missing from aggregate

```
! Auto-set with aggregate
aggregate-address 10.0.0.0 255.0.0.0 summary-only

! Suppress specific NLRI
aggregate-address 10.0.0.0 255.0.0.0 suppress-map filter-map

! View atomic aggregate
show ip bgp 10.0.0.0/8 | include Atomic
```

## Aggregator Attribute

- **Format:** `AS router-id`
- **Generated by:** Aggregation command
- **Use:** Know origin of aggregate

```
! View aggregator
show ip bgp 10.0.0.0/8 | include Aggregator
```

## Weight Attribute (Cisco-only)

- **Range:** 0-65535
- **Default:** 0
- **Direction:** Higher preferred
- **Scope:** Local router only (not advertised)

```
! Set weight via neighbor command
neighbor 10.0.0.1 weight 200

! Set weight via route-map
route-map weight-map in
  set weight 300

! For locally originated routes
route-map local-weight
  set weight 32768
```

## Complete Path Selection Order

1. **Weight** (Cisco-only, local)
2. **Local Preference** (iBGP)
3. **Locally Originated** (network/redistribute/aggregate)
4. **AS-Path Length** (shorter preferred)
5. **Origin Type** (IGP > EGP > Incomplete)
6. **MED** (if enabled, lower preferred)
7. **eBGP vs iBGP** (eBGP preferred)
8. **IGP Metric** (to next-hop)
9. **Cluster List** (shorter preferred)
10. **Router ID** (higher preferred)

## Attribute Manipulation Best Practices

1. Use communities for flexible policy
2. Prepend AS-path to discourage specific routes
3. Use local-preference for iBGP exit control
4. Use MED for entry point control
5. Document attribute meanings (RFCs)
6. Avoid manipulating too many attributes (complexity)
7. Monitor attribute values in debugging
8. Test policy changes in lab first
9. Use prefix-lists with route-maps
10. Implement clear, auditable policies
