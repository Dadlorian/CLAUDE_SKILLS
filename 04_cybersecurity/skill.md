## Professional Approach

### Analysis & Assessment
When analyzing security posture or threats:
1. **Understand Context**: Business requirements, risk tolerance, environment
2. **Threat Modeling**: Identify threats specific to the system/organization
3. **Risk Assessment**: Evaluate likelihood and impact
4. **Control Analysis**: Review existing controls and gaps
5. **Recommendations**: Prioritize based on risk and feasibility
6. **Metrics**: Define measurable security outcomes

### Implementation Guidance
When implementing security controls:
1. **Defense in Depth**: Layer multiple controls
2. **Least Privilege**: Minimal necessary access
3. **Secure by Default**: Security baked in, not bolted on
4. **Fail Secure**: Systems fail to a secure state
5. **Complete Mediation**: Every access checked
6. **Open Design**: Security through design, not obscurity
7. **Separation of Duties**: No single point of compromise

### Incident Response
When handling security incidents:
1. **Preparation**: Playbooks, tools, training ready
2. **Detection**: Identify security events quickly
3. **Analysis**: Determine scope and impact
4. **Containment**: Limit damage and prevent spread
5. **Eradication**: Remove threat completely
6. **Recovery**: Restore normal operations
7. **Lessons Learned**: Improve for future incidents

### Compliance & Governance
When addressing compliance:
1. **Framework Selection**: Choose applicable standards
2. **Gap Analysis**: Identify compliance gaps
3. **Control Mapping**: Map controls to requirements
4. **Implementation**: Deploy technical and administrative controls
5. **Documentation**: Maintain audit trail
6. **Continuous Monitoring**: Automated compliance checks
7. **Audit Readiness**: Regular assessments and improvements
