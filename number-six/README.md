## 🎯 Overview

**Number Six** is a professionally organized, production-grade skills system for Claude Code that combines:

- **Elite Cloud Skills**: Professional skill creation patterns and templates
- **Global Standards**: Comprehensive coding standards, style guides, and best practices
- **Rich Documentation**: Detailed guides for parallel execution and implementation
- **Production-Ready**: All skills follow industry-leading patterns from FAANG companies

This system represents a complete transformation from a flat file structure to a hierarchical, well-organized development ecosystem that rivals professional engineering organizations.

## 🌟 Key Features

### 1. Professional Cloud Skills
The `skills/cloud/` directory contains **professional-grade skill creators** that help you build custom Claude Code skills using proven patterns:

- **5 Skill Patterns**: Task Automation, Analysis & Review, Generation & Scaffolding, Transformation & Migration, Interactive Assistant
- **Production-Ready Templates**: Each pattern includes a complete template
- **Best Practice Guidance**: Step-by-step skill creation workflows
- **Real-World Examples**: Project management and mobile development skills

**Learn More**: See [skills/cloud/README.md](skills/cloud/README.md)

### 2. Comprehensive Standards Library

The `standards/` directory provides **industry-leading development standards**:

#### **coding-standards.md**
- **Multi-Language Support**: JavaScript/TypeScript, Python, Go
- **FAANG-Level Quality**: Based on Google, Airbnb, Microsoft style guides
- **Security-First**: OWASP Top 10 compliance, secure coding practices
- **Complete Examples**: ✅ Good vs ❌ Bad code comparisons
- **Testing Standards**: TDD, coverage thresholds, best practices

#### **rules.md**
- **7 Categories**: Security, Reliability, Performance, Quality, Testing, Git, Documentation
- **Non-Negotiable Standards**: Rules that prevent production incidents
- **Real-World Context**: Why each rule exists (based on actual incidents)
- **Enforcement Mechanisms**: Automated tools, CI/CD, code review
- **Emergency Override Process**: How to break rules when absolutely necessary

#### **best-practices.md**
- **Development Workflow**: TDD, feature branching, CI/CD
- **Architecture Patterns**: SOLID, DDD, dependency injection
- **Performance Optimization**: Caching, database, async processing
- **Security**: Authentication, authorization, sanitization
- **Monitoring**: Logging, metrics, distributed tracing
- **Skill Development**: Creating high-quality Claude Code skills

#### **style-guides/ui_ux_style_guide.md**
- **WCAG 2.2 AAA Compliance**: Accessibility excellence
- **Design Systems**: Material Design, Apple HIG, IBM Carbon
- **Typography & Color**: Professional scales and palettes
- **Component Standards**: Buttons, forms, tables, navigation
- **Performance**: Core Web Vitals, optimization techniques

### 3. Rich Documentation

The `docs/` directory contains **comprehensive guides** for execution and implementation:

- **MASTER_BLUEPRINT.md**: Overall architecture and domain definitions
- **QUICK_START.md**: 60-minute fast-track implementation
- **PARALLEL_EXECUTION_GUIDE.md**: Multi-skill parallel generation strategy
- **EXECUTION_CHECKLIST.md**: Step-by-step progress tracking
- **PROMPTS.md**: Ready-to-use prompts for all domains

### 4. Automation Scripts

The `scripts/` directory includes **automation tools**:

- **create_structure.sh**: Automated structure generation
- **verify_structure.sh**: Validation and quality checks

## 🚀 Quick Start

### For Skill Development

1. **Review Standards First**:
   ```bash
   # Read the foundational standards
   cat standards/coding-standards.md
   cat standards/rules.md
   cat standards/best-practices.md
   ```

2. **Explore Cloud Skill Patterns**:
   ```bash
   # Understand skill creation patterns
   cat skills/cloud/skill.md
   ls skills/cloud/templates/
   ```

3. **Create Your First Skill**:
   - Choose a pattern from `skills/cloud/templates/`
   - Follow the structure in the template
   - Apply standards from `standards/`
   - Reference examples in `skills/cloud/`

### For Project Implementation

   ```bash
   cat docs/QUICK_START.md
   ```

2. **Review the Blueprint**:
   ```bash
   cat docs/MASTER_BLUEPRINT.md
   ```

   ```bash
   cat docs/PARALLEL_EXECUTION_GUIDE.md
   ```

4. **Track Progress**:
   ```bash
   cat docs/EXECUTION_CHECKLIST.md
   ```
