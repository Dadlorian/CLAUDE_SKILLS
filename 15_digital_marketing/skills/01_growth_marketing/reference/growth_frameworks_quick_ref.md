# Growth Marketing Quick Reference
## AARRR Framework, North Star Metrics, ICE/RICE Scoring

### AARRR Pirate Metrics
- **Acquisition**: How users find you (channels, CAC, traffic sources)
- **Activation**: First positive experience (signup, onboarding, aha moment)
- **Retention**: Users coming back (DAU/MAU, cohort retention, churn rate)
- **Revenue**: Monetization (ARPU, LTV, conversion to paid)
- **Referral**: Viral growth (K-factor, referral rate, NPS)

### North Star Framework
**Definition**: Single metric that best captures core value delivered to customers
**Components**: North Star Metric + Input Metrics that drive it

**Examples**:
- Airbnb: Nights booked
- Spotify: Time spent listening
- Slack: Messages sent by teams
- Facebook: Daily active users

### ICE/RICE Prioritization
**ICE Score** = (Impact × Confidence × Ease) / 3
**RICE Score** = (Reach × Impact × Confidence) / Effort

### Growth Loops
1. **Viral Loop**: User invites → New user signs up → Invites more users
2. **Content Loop**: Create content → SEO traffic → New users → More content
3. **Paid Loop**: Ads → Customers → Revenue → More ad spend
4. **Sales Loop**: Customer success → Case study → Sales tool → More customers

### Key Metrics
- **CAC**: Customer Acquisition Cost
- **LTV**: Customer Lifetime Value
- **LTV/CAC Ratio**: Target 3:1 or higher
- **Payback Period**: Time to recover CAC (target <12 months)
- **Churn Rate**: Monthly/annual customer loss rate
- **NRR**: Net Revenue Retention (target >100%)
