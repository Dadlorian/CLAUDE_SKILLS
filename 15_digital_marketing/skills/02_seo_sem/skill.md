## Technical SEO Deep-Dive

### Core Web Vitals Optimization
- **Largest Contentful Paint (LCP)**: Load main content in < 2.5 seconds
  - Image optimization and lazy loading
  - Server-side rendering considerations
  - Font loading strategies
  - Third-party script management

- **First Input Delay (FID) / Interaction to Next Paint (INP)**:
  - Reduce JavaScript execution time
  - Code splitting and lazy loading
  - Web Workers for heavy computations
  - User interaction responsiveness

- **Cumulative Layout Shift (CLS)**:
  - Reserve space for dynamic content
  - Avoid inserting ads above content
  - Font loading strategies
  - Dimension attributes on media

### Crawlability & Indexation
- **XML Sitemaps**: Structure, priority, updatefreq attributes
- **Robots.txt**: Control crawler access, crawl budget management
- **Canonicalization**: Avoid duplicate content issues
- **Internal linking architecture**: Crawl depth and link flow
- **Crawl budget optimization**: Important for large sites (10,000+ pages)

### JavaScript SEO
- **Client-side rendering challenges**: Search bots may not execute JS
- **Server-side rendering (SSR)**: Pre-render content on server
- **Static site generation (SSG)**: Pre-build static files
- **Hydration**: Combining SSR with client-side interactivity
- **Testing with Google**: URL Inspection tool in GSC

### Mobile-First Indexing
- **Mobile experience is primary ranking signal**
- **Mobile viewport configuration**: Responsive design
- **Touch-friendly elements**: 48x48px minimum for clickable elements
- **Mobile page speed**: More critical than desktop
- **Mobile-specific testing**: Google Mobile-Friendly Test

## On-Page SEO Best Practices

### Title Tag Optimization
- Front-load target keyword (within first 50 characters)
- Include brand name for branded queries
- Keep under 60 characters for desktop, 40 for mobile
- Write for clicks (CTR affects rankings)
- Make unique for each page

### Meta Description Strategy
- Include primary keyword for emphasis
- Write benefit-driven descriptions (not just keywords)
- Call-to-action when relevant
- 155-160 characters for desktop, 120 for mobile
- Match search intent

### Header Tag Hierarchy
- Single H1 per page (usually page title)
- H2 for major sections
- H3 for subsections
- Use natural hierarchy (don't skip levels)
- Include keywords naturally

### Content Optimization
- **Search intent matching**: Exact match type to content type
- **Keyword variations**: Include synonyms and related terms
- **Content length**: 1,500-2,500+ words typically ranks better (for competitive terms)
- **Semantic SEO**: Cover related topics and concepts
- **EEAT signals**: Expertise, Experience, Authoritativeness, Trustworthiness

## Link Building & Off-Page SEO

### Link Profile Analysis
- **Backlink audit**: Using Ahrefs, SEMrush, Moz
- **Link quality assessment**:
  - Domain authority (DR)
  - Spam score
  - Anchor text quality
  - Contextual relevance
  - Link velocity (suspicious if sudden spikes)

### Link Building Strategies
- **Content-driven**: Create assets that earn links naturally
- **Digital PR**: Media coverage and mentions
- **Skyscraper technique**: Find popular content, create better version
- **Broken link building**: Find broken links on relevant sites
- **Resource page links**: Add to relevant resource compilations
- **Authority site contributions**: Interviews, roundups, guest posts

### Anchor Text Best Practices
- **Partial match**: Include keywords naturally
- **Branded**: Brand name as anchor
- **Exact match**: Risky if overused (can trigger Google penalties)
- **Generic**: "Click here" (provides little SEO value)
- **Natural ratio**: Most links should be branded or natural

## Advanced SEM Strategies

### Google Ads Account Structure
- **Campaign level**: Group by intent (brand, competitor, product)
- **Ad group level**: Specific keyword themes
- **Keyword matching**: Broad match, phrase match, exact match
- **Negative keywords**: Prevent irrelevant impressions

### Quality Score Optimization
- Quality Score (1-10) impacts CPC and ad position
- **Factors**:
  - CTR (click-through rate)
  - Ad relevance
  - Landing page experience
- **Optimization**:
  - Write compelling ad copy
  - Match ad to landing page
  - Improve page speed and UX
  - Test different ad variations

### Advanced Bid Strategies
- **Target CPA (Cost Per Acquisition)**:
  - Requires conversion tracking
  - Let Google optimize bids to hit target
  - Needs 30+ conversions in past month
  - Best for e-commerce and lead gen

- **Target ROAS (Return on Ad Spend)**:
  - Requires conversion value tracking
  - Optimizes for revenue
  - More sophisticated than CPA
  - Ideal for high-margin products

- **Maximize Conversions**:
  - Google spends full budget to get maximum conversions
  - No target CPA/ROAS
  - Good for awareness or list building

### Remarketing Strategy
- **Audience segments**:
  - People who visited product pages but didn't buy
  - People who abandoned checkout
  - Existing customers (upsell/cross-sell)
  - Video watchers
  - YouTube viewers

- **Bid adjustments**: Increase bids for warm audiences
- **Creative variations**: Different messaging for different stages

## Common SEO Mistakes & Fixes

| Problem | Impact | Solution |
|---------|--------|----------|
| Thin content | Poor rankings | Expand to 1,500+ words, improve depth |
| Slow page speed | High bounce rate | Image optimization, CDN, lazy loading |
| Poor mobile UX | Low rankings | Responsive design, fast mobile loading |
| Weak internal linking | Poor crawl depth | Link to important pages from homepage/nav |
| Duplicate content | Ranking cannibalization | Use canonical tags, combine similar pages |
| Outdated content | Lower rankings over time | Regular updates, refresh strategy |
| Keyword stuffing | Spam penalties | Natural keyword integration |

## Common SEM Mistakes & Fixes

| Problem | Impact | Solution |
|---------|--------|----------|
| High CPA | Poor ROI | Review landing page, improve ad copy |
| Low CTR | Wasted impressions | A/B test headlines, improve ad copy |
| Poor Quality Score | High CPC | Match ad to landing page, improve UX |
| No negatives | Wasted budget | Regularly review search terms, add negatives |
| No mobile optimization | Lower conversion rate | Ensure mobile-friendly landing pages |

## Enterprise SEO Implementation

### Large-Scale Site Optimization
**Challenges with 10,000+ pages**:
- Crawl budget constraints (not all pages crawled every day)
- Internal linking complexity
- Duplicate content issues at scale
- Mobile optimization across all pages
- International SEO considerations

**Crawl Budget Management**:
- Prioritize important pages (high-value URLs)
- Use noindex for thin/duplicate content
- Optimize internal linking to important pages
- Remove old, low-value content
- Use sitemaps to guide crawlers

**International SEO**:
- **hreflang tags**: Link related pages across languages
- **Country targeting**: Use Google Search Console
- **Local domains**: Country-specific domains better than subfolders
- **Local content**: Culturally relevant content for each market
- **Local citations**: Build links from local domains

## SEM Performance Optimization Frameworks

### Quality Score Improvement Playbook

**Audit existing accounts**:
1. Identify campaigns with quality score < 5
2. Review landing page experience
3. Check CTR by keyword/ad combination
4. Identify top bottleneck

**Improvement plan**:
- **CTR improvement**: Better ad copy, stronger CTA, Ad customizers
- **Relevance improvement**: Reorganize ad groups, better keyword match
- **Landing page improvement**: Faster loading, mobile optimization, message match

**Expected results**:
- Quality Score increase: 1-3 points improvement
- CPC decrease: 10-30% reduction
- CTR increase: 5-20% improvement

### ROAS Optimization Playbook

**Baseline measurement**:
1. Implement conversion tracking (revenue)
2. Calculate current ROAS by channel/campaign
3. Set targets (e.g., 3:1 ROAS)
4. Identify gap

**Optimization tactics**:
- **High-ROAS campaigns**: Increase budget, expand keywords
- **Low-ROAS campaigns**: Pause underperformers, optimize top performers
- **Keyword-level analysis**: Which keywords drive best ROAS?
- **Creative testing**: Test new ad copy, landing pages
- **Audience refinement**: Exclude underperforming demographics

**Measurement**:
- Revenue per click improvement
- Order value by source
- Customer lifetime value by channel
