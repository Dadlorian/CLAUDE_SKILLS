# SEO Quick Reference
## Essential SEO Tactics and Technical Requirements

### Technical SEO Checklist
- ✅ HTTPS enabled (SSL certificate)
- ✅ Mobile-friendly (responsive design)
- ✅ Core Web Vitals passing (LCP <2.5s, FID <100ms, CLS <0.1)
- ✅ XML sitemap submitted to Google Search Console
- ✅ Robots.txt configured correctly
- ✅ Structured data implemented (Schema.org)
- ✅ Canonical tags set properly
- ✅ No crawl errors or broken links

### On-Page SEO Essentials
- **Title Tag**: 50-60 characters, keyword at beginning
- **Meta Description**: 150-160 characters, compelling CTA
- **H1**: One per page, includes primary keyword
- **URL Structure**: Short, descriptive, includes keyword
- **Internal Links**: 3-5 per page to related content
- **Image Alt Text**: Descriptive, includes keyword when relevant
- **Page Speed**: <3 seconds load time

### Keyword Research Process
1. Seed keywords → Use tools (Ahrefs, SEMrush)
2. Analyze search volume, difficulty, intent
3. Group by topic clusters
4. Map to buyer journey stage
5. Prioritize by opportunity (high volume, low competition)

### Link Building Tactics
- Guest posting on authority sites
- Digital PR (HARO, journalist outreach)
- Broken link building
- Resource page link insertion
- Competitor backlink analysis
- Skyscraper technique (improve + promote content)
