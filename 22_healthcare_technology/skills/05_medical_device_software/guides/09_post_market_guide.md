# Post-Market Surveillance and Complaint Handling Guide

## Complaint Management System

### Complaint Receipt
**Information Captured**
- Date and time of report
- Reporter name and contact
- Device information (model, serial, version)
- Patient/user information
- Problem description
- Use circumstances
- Patient outcome
- Supporting evidence

### Initial Assessment
- Severity classification (critical/major/minor)
- Urgency level
- Immediate safety concerns
- Assignment for investigation

## Investigation Process

### Root Cause Analysis

**5 Why Technique**
1. What happened? (Problem description)
2. Why did it happen? (Immediate cause)
3. Why did that happen? (Deeper cause)
4. Why did that happen? (Root cause)
5. Why did that happen? (Systemic cause)

**Investigation Documentation**
- Problem statement
- Timeline of events
- Device examination results
- Test results
- User interviews
- Environmental factors
- Similar complaints search

## Corrective Action

### Options Evaluation
1. **Design Change**: Modify device/software
2. **Process Change**: Modify manufacturing/QA
3. **Training**: Improve user education
4. **Labeling**: Update instructions
5. **Recall**: Remove from market (if serious)

### Implementation
- Engineering design and approval
- Manufacturing verification
- User communication plan
- Deployment tracking
- Effectiveness monitoring

## Medical Device Reporting (MDR)

### When to Report to FDA
- Death caused or contributed to
- Serious injury (permanent or temporary)
- Serious illness (life-threatening)
- Malfunction that would likely cause adverse event

### Reporting Timeline
- Deaths: 15 days
- Serious injuries/illnesses: 30 days
- Expedited reporting for emergencies

### MDR Content
- Device identification
- Event description
- Patient outcome
- Investigation findings
- Corrective actions
- Manufacturer certification

## Trend Analysis

### Complaint Database
- Centralized system for all complaints
- Searchable by device, problem type, date
- Status tracking
- Investigation results
- Corrective actions

### Analysis Methods
- Frequency counting
- Time series analysis
- Pareto analysis (most common issues)
- Pattern identification
- Correlation analysis

### Triggers for Investigation
- X complaints of same type
- Serious injury reported
- Regulatory alert
- Trend increase detected
- New hazard pattern
