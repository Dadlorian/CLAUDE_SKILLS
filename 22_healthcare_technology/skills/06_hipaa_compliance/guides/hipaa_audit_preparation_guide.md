# HIPAA Audit Preparation Guide

## OCR Audit Protocol

OCR conducts audits to assess HIPAA compliance. Audits may be:
- Desk audits (document review)
- On-site audits (facility visits)
- Announced or unannounced

## Audit Focus Areas

**Privacy Rule:**
- Notice of Privacy Practices
- Individual access rights
- Accounting of disclosures
- Business associate agreements
- Minimum necessary

**Security Rule:**
- Security risk analysis
- Risk management
- Access controls
- Audit controls
- Encryption
- Business associate management

**Breach Notification:**
- Breach assessment process
- Notification procedures
- Documentation

## Pre-Audit Preparation

### 1. Conduct Self-Assessment

Review compliance with all HIPAA requirements:
- Complete internal audit using OCR protocol
- Identify gaps
- Remediate findings
- Document compliance efforts

### 2. Organize Documentation

**Privacy Documentation:**
- [ ] Notice of Privacy Practices (current version)
- [ ] NPP distribution documentation
- [ ] Individual rights request logs
- [ ] Authorization forms
- [ ] Accounting of disclosures
- [ ] Business associate agreements
- [ ] Privacy policies and procedures
- [ ] Complaint logs
- [ ] Sanction records
- [ ] Training records

**Security Documentation:**
- [ ] Security risk assessments (current + historical)
- [ ] Risk remediation plans
- [ ] Security policies and procedures
- [ ] Business associate agreements
- [ ] Access control documentation
- [ ] Audit log review documentation
- [ ] Incident response plans
- [ ] Contingency plans
- [ ] Disaster recovery test results
- [ ] Training records
- [ ] Annual evaluations

**Breach Documentation:**
- [ ] Breach log (all incidents)
- [ ] Breach risk assessments (4-factor)
- [ ] Notification documentation
- [ ] HHS submissions

### 3. Prepare Audit Response Team

**Team Members:**
- Privacy Official (lead)
- Security Official
- Compliance Officer
- IT Director
- Legal Counsel
- HR Representative
- Department managers (as needed)

**Team Preparation:**
- Review audit protocol
- Assign responsibilities
- Practice responses
- Identify spokespersons

### 4. Create Document Repository

Organize all compliance documents:
- Electronic document management system
- Clear folder structure
- Version control
- Quick retrieval capability
- Backup copies

### 5. Review and Update

**30 Days Before (If Announced):**
- Update all policies
- Complete any overdue training
- Finish any pending remediation
- Conduct final self-assessment
- Prepare document summaries

## During the Audit

### Document Requests

**OCR Will Request:**
- Policies and procedures
- Risk assessments
- Training records
- BAAs
- Individual rights request logs
- Incident reports
- Audit logs
- Sample PHI access reports
- Sanctions documentation

**Response Tips:**
- Provide exactly what's requested
- Don't volunteer extra information
- Use tracking log for all requests
- Document what was provided and when
- Keep copies of everything submitted
- Meet deadlines (request extensions if needed)

### Interviews

**OCR May Interview:**
- Privacy and Security Officials
- Executive leadership
- IT staff
- Clinical staff
- Administrative staff
- Patients (possibly)

**Interview Tips:**
- Be truthful and accurate
- Don't speculate or guess
- "I don't know but I'll find out" is acceptable
- Stay calm and professional
- Answer only the question asked
- Don't volunteer information
- Have team member take notes

### Site Visits

**OCR May Inspect:**
- Physical security measures
- Workstation positioning
- Access controls
- Server rooms
- Disposal procedures
- Visitor management
- Workstation use compliance

**Preparation:**
- Conduct pre-audit facility walkthrough
- Address any obvious issues
- Brief staff on audit presence
- Assign escort personnel
- Have documents readily available

## Common Audit Findings

### Privacy Rule
1. No Notice of Privacy Practices provided
2. Individual access requests not timely
3. Excessive fees for copies
4. No accounting of disclosures
5. Missing BAAs
6. No minimum necessary policies

### Security Rule
1. No security risk analysis conducted
2. Risk analysis incomplete
3. No risk remediation plan
4. Missing policies and procedures
5. No audit controls
6. No encryption (without documented decision)
7. Inadequate access controls
8. No business associate management
9. No training program
10. No contingency plan testing

### Breach Notification
1. Breaches not reported to HHS
2. Untimely individual notifications
3. Inadequate breach risk assessment
4. Poor breach documentation

## Responding to Findings

### Corrective Action Plan

OCR may require CAP if deficiencies found:

**CAP Components:**
1. Acknowledge finding
2. Describe corrective action
3. Assign responsibility
4. Set completion timeline
5. Describe how to prevent recurrence
6. Provide evidence of completion

**Example CAP:**
```
Finding: No security risk assessment conducted in past 3 years

Corrective Action:
1. Engage qualified consultant to conduct comprehensive SRA
   Responsible: Security Official
   Completion: 90 days

2. Develop risk remediation plan
   Responsible: Security Official
   Completion: 120 days

3. Implement annual SRA schedule
   Responsible: Security Official
   Completion: 90 days

4. Document SRA in policies and procedures
   Responsible: Compliance Officer
   Completion: 60 days

Prevention:
- Calendar reminder for annual SRA
- Board reporting on compliance activities
- Compliance checklist with SRA as line item
- Executive accountability for compliance

Evidence:
- Completed SRA report
- Board meeting minutes documenting review
- Updated policy with SRA procedures
- Calendar invitation for annual SRA
```

### Monitoring Period

OCR may require monitoring period (typically 2-3 years):

**Requirements:**
- Periodic compliance reports
- Documentation of corrective actions
- Ongoing self-monitoring
- Response to OCR inquiries

**Best Practices:**
- Submit reports on time
- Be thorough and accurate
- Document everything
- Proactive communication
- Maintain compliance beyond CAP items

## Post-Audit Actions

**Regardless of Outcome:**
1. Document lessons learned
2. Update compliance program
3. Enhance training
4. Improve documentation
5. Strengthen policies
6. Invest in tools/resources
7. Maintain vigilance

**If No Findings:**
- Don't become complacent
- Continue compliance efforts
- May still be audited again

**If Findings Identified:**
- Execute CAP fully
- Document all actions
- Report progress to OCR
- Learn from experience
- Prevent recurrence

## Audit Readiness Checklist

**Documentation:**
- [ ] All policies current and documented
- [ ] SRA completed within past year
- [ ] Risk remediation plan in place
- [ ] Training records complete
- [ ] BAAs executed with all vendors
- [ ] Individual rights requests logged and fulfilled
- [ ] Incident response plan documented and tested
- [ ] Contingency plan tested
- [ ] Breach log maintained
- [ ] All required logs available

**Organizational:**
- [ ] Privacy Official designated
- [ ] Security Official designated
- [ ] Audit response team identified
- [ ] Document repository organized
- [ ] Legal counsel identified
- [ ] Insurance coverage reviewed

**Technical:**
- [ ] Audit logging enabled
- [ ] Access controls implemented
- [ ] Encryption deployed
- [ ] Automatic logoff configured
- [ ] Audit log review documented
- [ ] Vulnerability scans current

**Physical:**
- [ ] Facility access controls in place
- [ ] Workstation security compliant
- [ ] Visitor management implemented
- [ ] Disposal procedures followed
- [ ] Certificates of destruction retained

**Ongoing:**
- [ ] Annual self-assessments
- [ ] Quarterly compliance reviews
- [ ] Board reporting
- [ ] Vendor management
- [ ] Continuous improvement
