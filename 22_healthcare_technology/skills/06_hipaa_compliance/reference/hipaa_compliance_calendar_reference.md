# HIPAA Compliance Calendar Reference

## Annual Compliance Activities

### Q1 (January - March)

#### January

**Week 1-2:**
- [ ] **Security Risk Assessment Planning**
  - Schedule annual security risk assessment
  - Assign responsibility and resources
  - Review previous year's assessment
  - Update assessment scope and methodology

- [ ] **Annual Report Submission to HHS**
  - Submit breaches affecting <500 individuals from previous year
  - Deadline: 60 days after calendar year-end (typically March 1)
  - Via HHS breach portal
  - Verify submission confirmation

- [ ] **Policy and Procedure Annual Review**
  - Begin annual review of all HIPAA policies
  - Update based on regulatory changes
  - Incorporate lessons learned from previous year
  - Update for environmental/operational changes

**Week 3-4:**
- [ ] **Business Associate Agreement Review**
  - Review all BAAs for expiration dates
  - Identify new vendors needing BAAs
  - Update BAA inventory
  - Send renewal notices for expiring BAAs

- [ ] **Training Program Planning**
  - Schedule annual HIPAA training sessions
  - Update training materials
  - Identify role-specific training needs
  - Plan new hire training schedule

#### February

**Week 1-2:**
- [ ] **Security Risk Assessment Execution**
  - Conduct comprehensive risk analysis
  - Update asset inventory
  - Interview key personnel
  - Review technical controls
  - Assess administrative safeguards
  - Evaluate physical security

**Week 3-4:**
- [ ] **Risk Assessment Documentation**
  - Document all findings
  - Identify vulnerabilities and threats
  - Calculate risk levels
  - Develop remediation recommendations
  - Create risk remediation plan

- [ ] **Annual Training Kickoff**
  - Begin delivering annual HIPAA training
  - Track attendance and completion
  - Document training sessions
  - Make available online/on-demand

#### March

**Week 1-2:**
- [ ] **Risk Remediation Planning**
  - Prioritize risks by severity
  - Assign remediation responsibilities
  - Set deadlines for corrective actions
  - Allocate budget and resources
  - Begin implementing high-priority fixes

**Week 3-4:**
- [ ] **Quarterly Audit Log Review**
  - Review Q1 audit logs
  - Analyze access patterns
  - Investigate anomalies
  - Document review findings
  - Follow up on suspicious activity

- [ ] **Disaster Recovery Plan Testing**
  - Schedule DR plan test
  - Test backup restoration
  - Verify recovery procedures
  - Document test results
  - Update plan based on test findings

### Q2 (April - June)

#### April

**Week 1-2:**
- [ ] **Policy Distribution and Acknowledgment**
  - Distribute updated policies
  - Obtain workforce acknowledgments
  - Update policy distribution logs
  - File acknowledgments

**Week 3-4:**
- [ ] **Physical Security Assessment**
  - Inspect facility access controls
  - Review visitor logs
  - Test badge access systems
  - Evaluate workstation security
  - Check media disposal procedures

- [ ] **Mobile Device Security Review**
  - Inventory all mobile devices with ePHI access
  - Verify encryption enabled
  - Check remote wipe capability
  - Review BYOD compliance
  - Update mobile device inventory

#### May

**Week 1-2:**
- [ ] **Business Associate Due Diligence**
  - Conduct BA compliance assessments
  - Request SOC 2 reports or equivalent
  - Review BA incident reports
  - Evaluate BA security practices
  - Document due diligence activities

**Week 3-4:**
- [ ] **Access Control Review**
  - Review user access permissions
  - Verify role-based access control
  - Remove terminated user access
  - Audit privileged accounts
  - Document access recertification

- [ ] **Encryption Verification**
  - Verify encryption on all ePHI at rest
  - Check transmission encryption (TLS 1.2+)
  - Test mobile device encryption
  - Review encryption key management
  - Document encryption status

#### June

**Week 1-2:**
- [ ] **Quarterly Audit Log Review**
  - Review Q2 audit logs
  - Analyze access patterns
  - Investigate anomalies
  - Document review findings
  - Escalate issues as needed

**Week 3-4:**
- [ ] **Mid-Year Compliance Assessment**
  - Review progress on remediation plan
  - Assess training completion rates
  - Evaluate policy compliance
  - Check BAA status
  - Identify mid-year adjustments needed

- [ ] **Incident Response Plan Review**
  - Review and update incident response plan
  - Update contact lists
  - Verify escalation procedures
  - Review breach notification templates
  - Conduct tabletop exercise

### Q3 (July - September)

#### July

**Week 1-2:**
- [ ] **Contingency Plan Testing**
  - Test data backup procedures
  - Verify off-site backup storage
  - Test backup restoration
  - Review recovery time objectives (RTO)
  - Review recovery point objectives (RPO)
  - Document test results

**Week 3-4:**
- [ ] **Workforce Security Review**
  - Review background check procedures
  - Verify termination procedures
  - Audit security awareness
  - Check sanction policy application
  - Document workforce security measures

- [ ] **Training Mid-Year Push**
  - Follow up on incomplete training
  - Schedule make-up sessions
  - Send reminders to non-completers
  - Update training completion tracking

#### August

**Week 1-2:**
- [ ] **Technical Safeguards Assessment**
  - Review authentication mechanisms
  - Verify unique user identification
  - Test automatic logoff
  - Assess audit control implementation
  - Evaluate transmission security

**Week 3-4:**
- [ ] **Vulnerability Scanning**
  - Conduct vulnerability scans
  - Review scan results
  - Prioritize remediation
  - Apply critical patches
  - Document scanning activity

- [ ] **Penetration Testing (Annual or Biennial)**
  - Engage penetration testing vendor
  - Scope testing activities
  - Review findings
  - Develop remediation plan
  - Retest critical findings

#### September

**Week 1-2:**
- [ ] **Quarterly Audit Log Review**
  - Review Q3 audit logs
  - Analyze access patterns
  - Investigate anomalies
  - Document review findings
  - Track issues to resolution

**Week 3-4:**
- [ ] **Emergency Access Procedure Review**
  - Review break-glass account usage
  - Verify emergency access logging
  - Test emergency access procedures
  - Update emergency contact lists
  - Document emergency access reviews

- [ ] **Privacy Practices Review**
  - Review Notice of Privacy Practices
  - Check individual rights compliance
  - Verify authorization processes
  - Assess minimum necessary compliance
  - Review disclosures for accounting

### Q4 (October - December)

#### October

**Week 1-2:**
- [ ] **Annual Evaluation Planning**
  - Schedule annual Security Rule evaluation
  - Assign evaluation team
  - Develop evaluation scope
  - Gather documentation for review

**Week 3-4:**
- [ ] **Business Continuity Planning**
  - Review business continuity plan
  - Update critical function identification
  - Test emergency mode operations
  - Verify alternative processing site
  - Update communication plans

- [ ] **Vendor Management Review**
  - Review all vendor contracts
  - Verify BAAs in place
  - Assess vendor performance
  - Identify vendors to be replaced
  - Plan vendor audits for next year

#### November

**Week 1-2:**
- [ ] **Annual Security Rule Evaluation**
  - Conduct comprehensive evaluation
  - Review all administrative safeguards
  - Assess physical safeguards
  - Evaluate technical safeguards
  - Review organizational requirements
  - Document evaluation findings

**Week 3-4:**
- [ ] **Breach Log Review**
  - Review all security incidents from year
  - Assess breach response effectiveness
  - Identify improvement opportunities
  - Update breach response procedures
  - Ensure <500 breaches logged for annual reporting

- [ ] **Training Completion Verification**
  - Verify all workforce completed training
  - Follow up on non-completers
  - Document training completion
  - Apply sanctions for non-compliance
  - Plan next year's training

#### December

**Week 1-2:**
- [ ] **Quarterly Audit Log Review**
  - Review Q4 audit logs
  - Analyze access patterns
  - Investigate anomalies
  - Document review findings
  - Year-end trend analysis

**Week 3-4:**
- [ ] **Year-End Compliance Summary**
  - Compile annual compliance report
  - Summarize risk assessment findings
  - Report training completion
  - Document incidents and responses
  - Present to senior management

- [ ] **Next Year Planning**
  - Budget for compliance activities
  - Plan major initiatives
  - Schedule next year's activities
  - Update compliance calendar
  - Assign responsibilities for upcoming year

- [ ] **Documentation Retention Review**
  - Review 6-year retention requirement
  - Archive old documentation
  - Dispose of expired records
  - Verify backup of retained records
  - Update retention schedule

## Monthly Compliance Activities

### Every Month

**Week 1:**
- [ ] **Security Incident Review**
  - Review previous month's incidents
  - Analyze incident trends
  - Verify incidents properly documented
  - Assess incident response effectiveness
  - Update incident tracking log

- [ ] **Access Provisioning/Deprovisioning Audit**
  - Review new user accounts created
  - Verify terminated user accounts disabled
  - Check role changes processed
  - Audit privileged account assignments
  - Document access changes

**Week 2:**
- [ ] **Patch Management Review**
  - Review critical patches released
  - Assess applicability to environment
  - Schedule patch deployment
  - Track patch installation
  - Document patching activity

- [ ] **Backup Verification**
  - Verify backups completed successfully
  - Test random backup restoration
  - Check off-site backup transfer
  - Review backup logs for errors
  - Document backup verification

**Week 3:**
- [ ] **Business Associate Monitoring**
  - Review BA incident reports
  - Check BA compliance attestations
  - Address BA-reported issues
  - Update BA risk assessments
  - Document BA interactions

- [ ] **User Account Review**
  - Identify dormant accounts
  - Review accounts for appropriate access
  - Verify no shared accounts
  - Check for excessive permissions
  - Document account review

**Week 4:**
- [ ] **Physical Security Inspection**
  - Walk through facilities
  - Check door locks and access controls
  - Verify visitor management compliance
  - Inspect workstation positioning
  - Review disposal bin contents
  - Document inspection findings

- [ ] **Compliance Metrics Tracking**
  - Track key performance indicators
  - Monitor training completion rates
  - Review incident response times
  - Assess audit log review completion
  - Report metrics to management

## Weekly Compliance Activities

### Every Week

**Monday:**
- [ ] Review weekend security alerts
- [ ] Check automated monitoring reports
- [ ] Review failed login attempts from weekend
- [ ] Address urgent security issues

**Tuesday:**
- [ ] Review previous week's audit log summary
- [ ] Follow up on open security incidents
- [ ] Check backup completion status
- [ ] Review access requests queue

**Wednesday:**
- [ ] Conduct staff security awareness reminder
- [ ] Review and approve pending access changes
- [ ] Check vulnerability scanning alerts
- [ ] Update incident tracking

**Thursday:**
- [ ] Review business associate communications
- [ ] Check compliance with policies and procedures
- [ ] Monitor training completion progress
- [ ] Address escalated issues

**Friday:**
- [ ] Week-end wrap-up and documentation
- [ ] Prepare weekly compliance summary
- [ ] Review upcoming week's activities
- [ ] Ensure weekend coverage arrangements

## Event-Driven Activities

### When Events Occur

**Security Incident Detected:**
- [ ] Immediate containment
- [ ] Incident response team activation
- [ ] Investigation initiation
- [ ] Documentation start
- [ ] Management notification
- [ ] Breach assessment if PHI involved

**Breach Confirmed:**
- [ ] Risk assessment (4 factors)
- [ ] Individual notification (within 60 days)
- [ ] HHS notification (if 500+)
- [ ] Media notification (if 500+)
- [ ] Documentation
- [ ] Post-incident review

**New Vendor/Business Associate:**
- [ ] Identify if PHI involved
- [ ] Conduct due diligence
- [ ] Execute BAA
- [ ] Add to vendor inventory
- [ ] Schedule periodic assessment

**Regulatory Change:**
- [ ] Review new requirements
- [ ] Gap analysis
- [ ] Policy updates
- [ ] Training updates
- [ ] Implementation plan
- [ ] Compliance verification

**System Implementation/Upgrade:**
- [ ] Security assessment
- [ ] Privacy impact assessment
- [ ] BAA review if vendor involved
- [ ] Testing in non-production
- [ ] Go-live security checklist
- [ ] Post-implementation review

**Workforce Changes:**

**New Hire:**
- [ ] Background check (if required)
- [ ] HIPAA training before PHI access
- [ ] Access provisioning
- [ ] Acknowledgment of policies
- [ ] Document onboarding

**Termination:**
- [ ] Immediate access removal
- [ ] Badge/key collection
- [ ] Device retrieval
- [ ] Exit interview
- [ ] Document termination

**Role Change:**
- [ ] Access review
- [ ] Role-appropriate access provisioning
- [ ] Remove inappropriate access
- [ ] Update training if needed
- [ ] Document change

## Compliance Reporting Schedule

### To Board/Senior Leadership

**Quarterly:**
- Compliance status summary
- Risk assessment updates
- Significant incidents
- Remediation progress
- Upcoming initiatives

**Annually:**
- Comprehensive compliance report
- Year-end metrics
- Annual evaluation results
- Budget and resource needs
- Strategic compliance plan

### To Privacy/Security Committee

**Monthly:**
- Incident summary
- Audit findings
- Policy updates
- Training status
- Vendor issues

**Quarterly:**
- Detailed compliance review
- Risk assessment updates
- Project status
- Regulatory updates
- Resource needs

### To HHS OCR

**As Required:**
- Breaches affecting 500+ (immediately)
- Breaches affecting <500 (annually by March 1)
- OCR investigations (as requested)
- Compliance reviews (if selected)

## State-Specific Requirements

### Consider State Variations

Some states have additional requirements:
- **California:** CMIA (Confidentiality of Medical Information Act)
- **Texas:** Medical Records Privacy Act
- **New York:** SHIELD Act
- **Massachusetts:** 201 CMR 17.00

**Action Items:**
- [ ] Identify applicable state laws
- [ ] Incorporate state requirements into calendar
- [ ] Ensure compliance with most stringent standard
- [ ] Document state-specific activities
