# Platform Requirements Reference

## Steam

### Requirements
- Steamworks SDK integration
- Age rating (IARC)
- Store page assets (capsules, screenshots)
- Build uploaded via SteamPipe

### Features
- Achievements (max 100)
- Cloud saves (max 100MB/user)
- Leaderboards
- Trading cards
- Workshop (UGC)

### Revenue Split
- 70% developer
- 30% Valve

## iOS App Store

### Requirements
- Apple Developer Program ($99/year)
- TestFlight for beta testing
- App Store Review Guidelines compliance
- Privacy policy required

### Technical
- Min iOS version support
- 64-bit builds required
- App size limit: 4GB over-the-air

### Revenue Split
- 70% developer (85% after year 1 subscription)
- 30% Apple (15% after year 1)

## Google Play

### Requirements
- Google Play Console ($25 one-time)
- Content rating (IARC)
- Privacy policy for apps with sensitive data

### Technical
- AAB (Android App Bundle) format
- Target latest API level
- 64-bit support required

### Revenue Split
- 85% developer
- 15% Google

## PlayStation/Xbox/Nintendo

### Requirements
- Approved developer status
- Development kit purchase
- Platform certification
- Age rating (ESRB, PEGI)

### Process
1. Apply for developer program
2. Pass technical certification
3. Pass content certification
4. Release approval

## Common Requirements

### Age Ratings
- ESRB (North America)
- PEGI (Europe)
- IARC (International)

### Legal
- Privacy policy
- Terms of service
- GDPR compliance (EU)
- COPPA compliance (children's games)
