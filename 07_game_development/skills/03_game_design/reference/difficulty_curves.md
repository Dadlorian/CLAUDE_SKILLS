# Difficulty Curves Reference

## Types of Curves

### Linear Progression
```
Difficulty ↑
          /
         /
        /
       /
Time →
```
**Use**: Puzzle games, educational games

### S-Curve (Skill Building)
```
Difficulty ↑
      ___/
    _/
   /
  /
Time →
```
**Use**: Most games, natural skill acquisition

### Sawtooth (Challenge-Rest)
```
Difficulty ↑
  /\  /\  /\
 /  \/  \/  \
Time →
```
**Use**: Action games, level-based progression

## Flow Channel
- Too easy = Boredom
- Too hard = Frustration
- Just right = Flow state

**Formula**: Challenge ≈ Player Skill × 1.1-1.3
