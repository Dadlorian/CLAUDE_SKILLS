# Core Gameplay Loops - Quick Reference

## What is a Gameplay Loop?

The cycle of actions players repeatedly perform in your game. Good loops are satisfying, clear, and escalate in complexity.

## Types of Loops

### 1. Moment-to-Moment (Second-to-Second)
**Duration**: < 10 seconds
**Examples**:
- **FPS**: Aim → Shoot → Kill → Move
- **Platformer**: Jump → Land → Run → Jump
- **Racing**: Steer → Brake → Accelerate
- **Fighting**: Block → Attack → Dodge

**Keys to Success**:
- ✅ Responsive controls (< 100ms latency)
- ✅ Clear visual/audio feedback
- ✅ Satisfying "game feel"
- ✅ Low barrier to entry

### 2. Short-Term (Minute-to-Minute)
**Duration**: 1-10 minutes
**Examples**:
- **RPG**: Quest → Combat → Loot → Level Up
- **Roguelike**: Floor → Fight → Upgrade → Next Floor
- **MOBA**: Lane → Fight → Farm → Push
- **Battle Royale**: Land → Loot → Rotate → Fight

**Keys to Success**:
- ✅ Clear objectives
- ✅ Visible progress
- ✅ Meaningful choices
- ✅ Risk/reward balance

### 3. Medium-Term (Session-to-Session)
**Duration**: 10-60 minutes (single session)
**Examples**:
- **Strategy**: Build → Attack → Defend → Expand
- **Survival**: Gather → Craft → Explore → Build
- **CCG**: Deck Build → Match → Adjust → Repeat
- **Puzzle**: Solve → Unlock → Next Level

**Keys to Success**:
- ✅ Natural stopping points
- ✅ Session variety
- ✅ Meta progression visible
- ✅ Reason to return

### 4. Long-Term (Day-to-Day, Week-to-Week)
**Duration**: Multiple sessions over days/weeks
**Examples**:
- **MMO**: Level → Raid → Gear → Prestige
- **Mobile**: Daily Login → Event → Gacha → Progress
- **Live Service**: Season → Battle Pass → Unlock → Next Season
- **Sandbox**: Build → Share → Iterate → Showcase

**Keys to Success**:
- ✅ Long-term goals
- ✅ Social features
- ✅ Regular content updates
- ✅ Meaningful progression

## Designing Effective Loops

### 1. Clear Entry Points
- Players know what to do first
- Tutorial introduces loop naturally
- Low friction to start

### 2. Satisfying Core Actions
- Primary actions feel good
- Immediate feedback
- "Juice" and polish

### 3. Escalating Complexity
- Early: Simple, safe experimentation
- Mid: New mechanics, combinations
- Late: Mastery, optimization

### 4. Meaningful Rewards
- Extrinsic: XP, loot, currency
- Intrinsic: Mastery, discovery, expression

### 5. Natural Rhythm
- Tension → Release → Tension
- Combat → Exploration → Downtime
- Challenge → Accomplishment → Challenge

## Common Loop Patterns

### Power Fantasy Loop
```
Weak → Power Up → Feel Strong → Stronger Enemy → Repeat
```
**Games**: Doom, Devil May Cry, Warframe

### Risk/Reward Loop
```
Safe → Risk → Reward → Invest → Bigger Risk → Repeat
```
**Games**: Dark Souls, Roguelikes, Poker

### Collection Loop
```
Explore → Find → Collect → Unlock → Explore More → Repeat
```
**Games**: Pokemon, Metroidvania, Collectathons

### Optimization Loop
```
Build → Test → Improve → Share → Build Better → Repeat
```
**Games**: Factorio, Satisfactory, SimCity

### Social Loop
```
Play → Share → Compare → Compete → Play Better → Repeat
```
**Games**: Among Us, Fall Guys, Party Games

## Balancing Multiple Loops

Good games layer loops:

**Celeste** (Platformer):
- **Moment**: Jump → Dash → Climb (tight controls)
- **Short**: Complete Room → Die → Retry → Success
- **Medium**: Complete Chapter → Unlock B-Side
- **Long**: Collect Strawberries → 100% Game

**Hades** (Roguelike):
- **Moment**: Attack → Dodge → Cast → Repeat
- **Short**: Clear Room → Choose Boon → Progress
- **Medium**: Complete Run → Unlock Weapon Aspect
- **Long**: Advance Story → Max Relationships

## Warning Signs

❌ **No Clear Loop**: Players don't know what to do next
❌ **Boring Core**: Loop feels tedious after first try
❌ **No Escalation**: Same actions all game long
❌ **Meaningless Rewards**: Rewards don't enable new play
❌ **Too Grindy**: Progress requires excessive repetition

## Testing Your Loop

### Questions to Ask:
1. Can you explain the core loop in one sentence?
2. Is the first iteration fun?
3. Is the 100th iteration still fun?
4. Do players naturally discover the loop?
5. Does the loop support your game's theme/fantasy?

### Playtest Observations:
- Do players engage with loop without prompting?
- Do they repeat loop voluntarily?
- When do they stop enjoying it?
- What causes friction or confusion?
