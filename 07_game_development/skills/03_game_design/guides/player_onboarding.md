# Player Onboarding Best Practices

## First-Time User Experience (FTUE)

### Goals
- Teach core mechanics
- Build confidence
- Create positive first impression
- Reduce churn in first session

### Principles
1. **Show, Don't Tell**: Interactive tutorials > text
2. **Just-In-Time**: Teach when needed
3. **Gradual Complexity**: One mechanic at a time
4. **Immediate Feedback**: Celebrate success
5. **Safe Practice**: Low stakes practice area

## Tutorial Structure

### Introduction (30 seconds)
- Hook: Exciting moment or story
- Context: What is this game?
- Goal: What will I do?

### Core Loop (2-5 minutes)
- Teach primary action
- Let player succeed
- Reward immediately
- Repeat 2-3 times

### Complexity Ramp (5-15 minutes)
- Introduce secondary mechanics
- Combine mechanics
- Increase difficulty gradually
- Provide optional challenges

## Common Mistakes
❌ Too much text
❌ Interrupting gameplay
❌ Teaching too many things at once
❌ No skip option for returning players
❌ Failure without explanation

## Metrics to Track
- % completing tutorial
- Time to complete tutorial
- Drop-off points
- Day 1 retention
- Tutorial skip rate (returning players)

## Examples
- **Hollow Knight**: Environmental teaching, no text
- **Portal**: Perfect gradual complexity
- **Celeste**: Practice room, positive messaging
- **Among Us**: Play-to-learn, minimal tutorial
