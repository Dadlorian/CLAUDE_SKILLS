## 📊 Performance Targets

Standard performance budgets referenced throughout:

### Frame Time (60 FPS = 16.67ms)
- **CPU Game Logic**: 8-10ms
- **Rendering**: 4-6ms
- **Physics**: 1-2ms
- **Audio**: 0.5-1ms
- **Other**: 1-2ms

### Memory Budgets (Platform-Specific)
- **Mobile (Low-End)**: 1-2GB total
- **Mobile (High-End)**: 3-4GB total
- **Console**: 8-12GB total (5-8GB available)
- **PC**: 8GB+ total (scalable)

### Network Performance
- **Tick Rate**: 20-60Hz (genre-dependent)
- **Client Latency**: <150ms acceptable, <50ms ideal
- **Bandwidth**: 50-200Kbps per client

### Build Times
- **Iterative Compilation**: <5 seconds (Unity), <10 seconds (Unreal)
- **Full Build**: <30 minutes for medium project
