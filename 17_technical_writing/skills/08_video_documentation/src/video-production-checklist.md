# Complete Video Production Workflow Checklist

## Overview
Professional comprehensive checklist for all phases of video production from concept to publication and promotion.

---

## PHASE 1: PRE-PRODUCTION PLANNING

### 1.1 Content Strategy & Research

**Audience & Goal Definition**
- [ ] Define target audience (skill level, demographics, pain points)
- [ ] Identify primary goal (educate, entertain, promote, persuade)
- [ ] Define success metrics (views, engagement, conversions, subscribers)
- [ ] Estimate target audience size and growth potential
- [ ] Research competitor videos on same topic
- [ ] Note what competitors do well
- [ ] Identify gaps or unique angles
- [ ] Decide on unique value proposition

**Keyword & Topic Research**
- [ ] Research primary keyword using:
  - [ ] YouTube autocomplete
  - [ ] Google Trends
  - [ ] VidIQ Keyword Tool
  - [ ] TubeBuddy Keyword Explorer
  - [ ] Google Search Console
- [ ] Identify secondary keywords
- [ ] Check search volume for target keyword
- [ ] Analyze competition level
- [ ] Document keyword strategy
- [ ] Plan for seasonal or trending angles
- [ ] Create keyword brief document

**Content Outline & Format**
- [ ] Decide video format (tutorial, vlog, comparison, list, etc.)
- [ ] Create detailed outline with sections
- [ ] Estimate duration for each section
- [ ] Plan total video length (optimal for topic)
- [ ] Identify key learning objectives
- [ ] Plan narrative arc or story structure
- [ ] Identify key points/takeaways
- [ ] Plan transitions between sections
- [ ] Design opening hook strategy
- [ ] Plan closing call-to-action

### 1.2 Script Development

**Script Writing**
- [ ] Write full script (don't wing it)
- [ ] Use conversational tone (write like you speak)
- [ ] Keep sentences short and clear
- [ ] Include natural pauses for breath
- [ ] Avoid filler words (um, uh, like, you know)
- [ ] Number paragraphs for easy reference
- [ ] Time the script (average 140-150 words per minute)
- [ ] Verify total timing is within target length
- [ ] Make script accessible for non-native speakers
- [ ] Review script for accuracy and clarity
- [ ] Have script reviewed by team member (fresh eyes)
- [ ] Get approval from stakeholders if needed
- [ ] Create speaker notes for difficult sections
- [ ] Mark where visuals/graphics should appear
- [ ] Highlight key points for emphasis

**Scriptwriting Best Practices**
- [ ] Start with hook (first 10 seconds are critical)
- [ ] State video promise early
- [ ] Use pattern interrupts (visual changes every 5-10 seconds)
- [ ] Include specific examples, not just theory
- [ ] Build from simple to complex concepts
- [ ] Summarize key points before moving on
- [ ] Use transition phrases ("Next, we're going to...")
- [ ] End with clear value statement
- [ ] Plan time for viewer interaction (if applicable)
- [ ] Include call-to-action placement (usually at end)

**Script Rehearsal**
- [ ] Read script aloud 3-5 times
- [ ] Record practice reading
- [ ] Review recording for pace and clarity
- [ ] Note sections that sound awkward
- [ ] Rewrite awkward sections for natural speech
- [ ] Practice pronunciation of technical terms
- [ ] Record final practice run
- [ ] Time the final practice run
- [ ] Adjust if needed to hit target duration
- [ ] Practice 2-3 more times until comfortable
- [ ] Record reference audio for editing (if needed)

### 1.3 Equipment & Technology Setup

**Recording Equipment Checklist**
- [ ] Video camera (phone, webcam, or dedicated camera)
- [ ] Test camera resolution (1920x1080 minimum)
- [ ] Test camera frame rate (30 or 60 fps)
- [ ] Microphone (USB, wireless, or built-in with test)
- [ ] Test microphone audio levels (-6dB to -3dB peak)
- [ ] Microphone stand or boom arm (if needed)
- [ ] Microphone pop filter (to reduce plosives)
- [ ] Audio interface (if using professional mic)
- [ ] Monitor/headphones for audio monitoring
- [ ] Lighting setup (3-point or key light)
- [ ] Test lighting for shadows and glare
- [ ] Tripod for camera stability
- [ ] Screen recording software (ScreenFlow, Camtasia, OBS)
- [ ] Screen recording resolution set to 1920x1080
- [ ] Screen recording frame rate set to 30 fps
- [ ] Backup power supply (battery or AC adapter)
- [ ] External hard drive for backup
- [ ] Secondary storage device for redundancy

**Software & Plugins**
- [ ] Video editing software installed (Premiere, DaVinci, Final Cut)
- [ ] Audio editing software installed (Audacity, Adobe Audition)
- [ ] Required plugins/filters installed
- [ ] Fonts downloaded and installed
- [ ] Motion graphics templates downloaded
- [ ] Overlay/graphics files organized
- [ ] Color grading presets loaded
- [ ] Export settings configured
- [ ] Backup of software licenses/keys secured

**Browser & Computer Setup (for screen recording)**
- [ ] Browser bookmarks organized
- [ ] Unnecessary tabs closed
- [ ] Notifications disabled (email, chat, etc.)
- [ ] Phone set to silent
- [ ] Do Not Disturb mode enabled
- [ ] Screen brightness set to comfortable level
- [ ] Font size readable (at least 16pt for code)
- [ ] Desktop background set to neutral
- [ ] Unnecessary programs closed
- [ ] Update all software before recording
- [ ] Restart computer before recording (fresh start)
- [ ] Clear cache and cookies (if privacy-relevant)
- [ ] Disable auto-updates during recording

### 1.4 Environment Preparation

**Recording Space Setup**
- [ ] Choose quiet location (minimal background noise)
- [ ] Close windows and doors
- [ ] Turn off air conditioning/heating during recording
- [ ] Turn off fans or other noise sources
- [ ] Arrange furniture/background for appeal
- [ ] Remove distracting items from background
- [ ] Ensure background is professional
- [ ] Position camera at eye level
- [ ] Position lighting to avoid shadows on face
- [ ] Position lighting to avoid glare on camera
- [ ] Adjust camera framing (rule of thirds)
- [ ] Test for adequate space to move (if needed)
- [ ] Place water nearby (throat lubrication)
- [ ] Use bathroom before recording
- [ ] Set phone to silent (not vibrate)
- [ ] Notify household of recording time
- [ ] Post "Do Not Disturb" sign if needed

**Lighting Setup (for on-camera content)**
- [ ] Key light: Position 45° angle, ~3-4 feet away
- [ ] Fill light: Opposite side, dimmer than key light
- [ ] Back light (optional): Behind subject, creates separation
- [ ] Adjust lights for even facial illumination
- [ ] Check for shadows under eyes or nose
- [ ] Verify no glare on glasses (if wearing)
- [ ] Test lighting on camera (not just in-person)
- [ ] Maintain consistent color temperature (all lights same temp)
- [ ] Use daylight-balanced lights (5600K) or tungsten (3200K)

**Audio Setup**
- [ ] Microphone positioned 6-12 inches from mouth
- [ ] Microphone positioned slightly off-axis (avoid plosives)
- [ ] Audio levels set correctly in recording software
- [ ] Monitor audio levels during test recording
- [ ] Test audio quality by recording 30-second sample
- [ ] Check for: hum, buzz, crackling, low volume
- [ ] Use headphones to monitor audio (catch issues early)
- [ ] Record audio on separate track (if possible)
- [ ] Disable auto-gain control (manual control is better)
- [ ] Set audio format to 48kHz, 24-bit (if available)

### 1.5 Content Asset Preparation

**Graphics & Visuals**
- [ ] Design intro graphics/title card
- [ ] Create chapter/section title cards
- [ ] Design outro graphics
- [ ] Prepare any diagrams or charts
- [ ] Prepare comparison graphics (if applicable)
- [ ] Screenshot any external sites/apps
- [ ] Prepare code examples or snippets
- [ ] Prepare text overlays
- [ ] Create transition graphics (if using custom)
- [ ] Organize all graphics in folder structure
- [ ] Name files clearly (not "Graphic1.psd")
- [ ] Verify all graphics are correct resolution
- [ ] Color correct graphics to match brand
- [ ] Create backup of all graphics

**Media Assets**
- [ ] License any music tracks
- [ ] Download music files (high quality)
- [ ] Prepare sound effects
- [ ] License any stock footage
- [ ] Download stock footage (highest quality available)
- [ ] Prepare any B-roll footage
- [ ] Organize all media in folders
- [ ] Create spreadsheet of asset sources/licenses
- [ ] Document music/footage in credits
- [ ] Verify all licensing allows commercial use

**Data & Resources**
- [ ] Prepare demo data/accounts (if needed)
- [ ] Document login credentials securely
- [ ] Prepare URLs for resources mentioned
- [ ] Test all URLs work before recording
- [ ] Prepare documents/files to share
- [ ] Organize resources in reference folder
- [ ] Create links document for description

## PHASE 2: RECORDING

### 2.1 Pre-Recording Setup

**Final System Check**
- [ ] Restart computer 30 minutes before recording
- [ ] Close all unnecessary programs
- [ ] Check internet connection speed (if cloud-based)
- [ ] Test audio levels one more time
- [ ] Test video recording one more time (30 seconds)
- [ ] Review the 30-second test recording
- [ ] Check lighting one more time
- [ ] Check microphone placement one more time
- [ ] Verify camera framing correct
- [ ] Test all software is working
- [ ] Create project file/session in editing software
- [ ] Set up recording location and naming convention
- [ ] Verify backup storage is connected
- [ ] Clear recording destination folder
- [ ] Disable notifications on all devices
- [ ] Set up phone on silent and away from recording area

**Mental Preparation**
- [ ] Review script one final time
- [ ] Mentally rehearse difficult sections
- [ ] Do vocal warmup exercises (5 minutes)
- [ ] Drink water
- [ ] Take 3 deep breaths
- [ ] Remind yourself the goal (who you're helping)
- [ ] Plan for multiple takes (don't expect perfection)
- [ ] Commit to getting the job done today

### 2.2 Recording Best Practices

**Starting the Recording**
- [ ] Set recording to start (verify it's actually recording)
- [ ] Let recording run for 2-3 seconds before starting
- [ ] Pause 1-2 seconds before speaking
- [ ] Speak clearly and at natural pace
- [ ] Speak slightly slower than normal conversation
- [ ] Maintain consistent volume throughout
- [ ] Make eye contact with camera (if on-camera)
- [ ] Use natural gestures (if on-camera)

**During Recording**
- [ ] Follow script but allow for natural variation
- [ ] If you make mistake, note timestamp and continue (fix in editing)
- [ ] Take a breath between sections
- [ ] Maintain energy throughout
- [ ] Monitor audio levels (via headphones)
- [ ] Check camera framing periodically (if moving)
- [ ] Pause if interrupted (aircraft, dog barking, etc.)
- [ ] Save video every 10-15 minutes (backup)
- [ ] Record in segments if long video (every 10-15 min)

**After Each Take**
- [ ] Let recording run 2-3 seconds after finishing
- [ ] Stop recording
- [ ] Review the take (listen/watch):
  - [ ] Did you follow the script?
  - [ ] Were there any stumbles or mistakes?
  - [ ] Was audio quality good?
  - [ ] Was pace appropriate?
  - [ ] Did you stay within time budget?
- [ ] Save/backup the recording
- [ ] Note if retake is needed or if this take is usable

**Multiple Takes Strategy**
- [ ] Plan to record 2-3 takes of each section
- [ ] Record more takes of difficult sections
- [ ] Take a break between takes (5-10 minutes)
- [ ] Reset microphone and camera between takes
- [ ] Check audio and video levels between takes
- [ ] Review script between takes
- [ ] For best take: note timings and marks used

### 2.3 Screen Recording (if applicable)

**Before Screen Recording**
- [ ] Close all unnecessary browser tabs
- [ ] Clear desktop of clutter
- [ ] Set up demo environment
- [ ] Test all demo functionality
- [ ] Open applications needed
- [ ] Zoom to appropriate level (content readable)
- [ ] Set screen resolution to 1920x1080
- [ ] Close all notifications
- [ ] Turn off auto-lock or screensaver
- [ ] Ensure no password reminders will pop up
- [ ] Use second monitor for notes/script (if possible)

**During Screen Recording**
- [ ] Move mouse slowly and deliberately
- [ ] Pause before each click (1-2 seconds)
- [ ] Pause after each action (2-3 seconds for comprehension)
- [ ] Don't skip around (follow logical progression)
- [ ] Highlight important elements with cursor/pointer
- [ ] Allow time for text to be read on screen
- [ ] Narrate everything (don't assume viewers understand)
- [ ] Use zoom in on important details (if screen is small)
- [ ] Test everything works before recording (no loading errors)
- [ ] Have backup demo if live environment is unstable
- [ ] Record in segments if content is long

**After Screen Recording**
- [ ] Verify recording quality
- [ ] Check that all actions are visible
- [ ] Verify audio is synchronized with video
- [ ] Verify no crashes or errors occurred
- [ ] Save backup immediately
- [ ] Verify backup file is intact

### 2.4 Post-Recording File Management

**Backup & Organization**
- [ ] Create backup of all recordings immediately
- [ ] Verify backup is complete and playable
- [ ] Create second backup on separate drive
- [ ] Organize all files in project folder
- [ ] Name files clearly with content + date
- [ ] Document file locations
- [ ] Create metadata file listing all recordings
- [ ] Verify integrity of all files
- [ ] Delete temporary/test recordings
- [ ] Keep organized file structure throughout editing

## PHASE 3: POST-PRODUCTION EDITING

### 3.1 Import & Organization

**Importing Footage**
- [ ] Import all video files into editing software
- [ ] Organize in bins/folders by type (video, audio, graphics)
- [ ] Review all imported files
- [ ] Verify proper audio sync
- [ ] Check for corrupted files
- [ ] Organize timeline with clear naming
- [ ] Create version naming system (v1, v2, etc.)
- [ ] Save project file frequently during editing
- [ ] Backup project file after each session

**Creating Project Structure**
- [ ] Create main sequence/timeline
- [ ] Create reference timeline for script/notes
- [ ] Create separate tracks for:
  - [ ] Video - primary recording
  - [ ] Video - B-roll
  - [ ] Video - graphics/motion
  - [ ] Audio - dialogue
  - [ ] Audio - music
  - [ ] Audio - sound effects
- [ ] Label tracks clearly
- [ ] Lock unused tracks
- [ ] Color-code tracks for organization

### 3.2 Video Editing

**Initial Assembly**
- [ ] Place primary video on timeline
- [ ] Trim out obvious mistakes/long pauses
- [ ] Remove sections that don't serve the content
- [ ] Cut out filler words and hesitations (if audible)
- [ ] Verify sequence is logical and flows well
- [ ] Add markers for sections that need work
- [ ] Review assembly (rough cut)
- [ ] Adjust length if needed to hit target duration

**Adding B-Roll & Graphics**
- [ ] Identify sections that need visual support
- [ ] Add B-roll footage at appropriate moments
- [ ] Add graphics/diagrams where needed
- [ ] Add text overlays for key points
- [ ] Add chapter title cards (if using)
- [ ] Verify graphics are readable
- [ ] Verify graphics enhance (not distract)
- [ ] Adjust opacity of overlays (usually 80-90%)
- [ ] Color-correct graphics to match overall look
- [ ] Time graphics to appear/disappear with narration

**Transitions & Pacing**
- [ ] Add transitions between sections (if appropriate)
- [ ] Use fade/dissolve for smooth transitions
- [ ] Avoid excessive transitions (distracting)
- [ ] Vary pacing (not constant slow or fast)
- [ ] Use pauses for emphasis (2-3 seconds)
- [ ] Cut on action (transitions feel natural)
- [ ] Match cuts to music beat (if applicable)
- [ ] Review entire video for pacing
- [ ] Adjust if any section feels slow or rushed

**Visual Effects & Color**
- [ ] Apply zoom/ken burn effects to static shots (subtle)
- [ ] Add slight pan to graphics for visual interest
- [ ] Apply color correction for consistency
- [ ] Adjust white balance if needed
- [ ] Slightly boost contrast/saturation
- [ ] Maintain consistent color temperature
- [ ] Color-grade to match brand aesthetic
- [ ] Check on different monitors (colors differ)
- [ ] Verify video is readable in all lighting

**Title & Lower-Third Graphics**
- [ ] Add main title at beginning
- [ ] Add lower-thirds for on-camera speakers
- [ ] Add text overlays for key points
- [ ] Time text to be readable (2-3 seconds minimum)
- [ ] Use consistent font and styling
- [ ] Use contrasting colors for readability
- [ ] Verify text doesn't overlap important content
- [ ] Check spelling and grammar of all text

### 3.3 Audio Editing & Mixing

**Dialogue/Voiceover Cleanup**
- [ ] Remove background noise with noise reduction tool
- [ ] Reduce hum (50/60 Hz depending on location)
- [ ] Normalize audio levels (bring to -3dB peak)
- [ ] Use gentle EQ to add clarity:
  - [ ] Boost 4-5kHz for presence
  - [ ] Boost 200-300Hz for warmth
  - [ ] Remove harshness around 3-4kHz if needed
- [ ] Remove plosives (p, b sounds) with EQ or de-esser
- [ ] Compress slightly for consistency (-3dB to -6dB range)
- [ ] Fade in/out at beginning/end (0.5 second)
- [ ] Add crossfades between segments (0.5 second)
- [ ] Level dialogue to consistent volume (-18dB average)

**Music & Sound Effects**
- [ ] Add background music to appropriate sections
- [ ] Adjust music level to not overpower dialogue (-20dB)
- [ ] Fade in music at beginning (1 second)
- [ ] Fade out music at end (1-2 seconds)
- [ ] Add sound effects for transitions (subtle)
- [ ] Add sound effects for emphasis (if appropriate)
- [ ] Layer multiple tracks if needed
- [ ] Create dynamic mix (not all same level)
- [ ] Test mix on different speakers

**Final Audio Mix**
- [ ] Balance all audio tracks
- [ ] Check dialogue is clear above music/effects
- [ ] Verify no clipping (peaks above 0dB)
- [ ] Verify no dead air (silence feels awkward)
- [ ] Add small amount of reverb for natural sound (optional)
- [ ] Use slight compression across entire mix for cohesion
- [ ] Master to -3dB peak, -18dB average
- [ ] Export separate audio reference for review
- [ ] Listen on multiple speakers (check translation)
- [ ] Listen on headphones (catch subtle issues)

**Audio Export**
- [ ] Export dialogue reference track
- [ ] Export full mix reference
- [ ] Verify exports are correct
- [ ] Archive audio files/project

### 3.4 Caption & Subtitle Creation

**Generating Captions**
- [ ] Use auto-generated captions as starting point
- [ ] Review auto-generated captions
- [ ] Correct all errors and misheard words
- [ ] Add speaker identification ([HOST]: text)
- [ ] Add sound descriptions [MUSIC], [APPLAUSE]
- [ ] Add timing/timestamps for navigation
- [ ] Break captions into readable chunks (7-10 words)
- [ ] Verify captions don't stay on screen too long
- [ ] Check caption synchronization with video
- [ ] Test readability of caption text

**Accessibility Compliance**
- [ ] All dialogue is captioned
- [ ] Sound effects are described
- [ ] Speaker changes are identified
- [ ] Music/background sounds are noted
- [ ] Important visual elements are described
- [ ] Caption text is large enough
- [ ] Captions have good contrast with background
- [ ] Captions don't block important visuals
- [ ] No spelling errors in captions
- [ ] Grammar is correct

**Export Captions**
- [ ] Export in SRT format (for YouTube)
- [ ] Export in VTT format (for website)
- [ ] Verify export format is correct
- [ ] Test captions on different devices
- [ ] Have proofreader review captions (fresh eyes)

### 3.5 Graphics & Motion Creation

**Intro Graphics**
- [ ] Design/create intro sequence (3-5 seconds)
- [ ] Include logo animation
- [ ] Include title/topic
- [ ] Add music/sound effect
- [ ] Color-match brand
- [ ] Verify animation is smooth
- [ ] Time animation to music beat (if applicable)

**Section/Chapter Graphics**
- [ ] Design chapter title cards (2-3 seconds each)
- [ ] Add chapter number
- [ ] Add chapter title
- [ ] Use consistent styling
- [ ] Time to appear/disappear with narration
- [ ] Verify readability

**Outro Graphics**
- [ ] Design outro sequence (5-10 seconds)
- [ ] Include call-to-action
- [ ] Include channel branding
- [ ] Add links/resources on screen
- [ ] Include subscribe button
- [ ] Include suggested next videos
- [ ] Add background music
- [ ] Time music to fade out smoothly

**Lower-Thirds & Text Overlays**
- [ ] Create lower-third template
- [ ] Design text overlays for key points
- [ ] Use consistent fonts and colors
- [ ] Test readability at various sizes
- [ ] Create template for reuse in future videos

### 3.6 Rough Cut Review

**Internal Review**
- [ ] Export rough cut
- [ ] Watch entire video start-to-finish
- [ ] Take notes on issues/improvements
- [ ] Check timing and pacing
- [ ] Verify content is accurate
- [ ] Verify narrative flow makes sense
- [ ] Check audio levels throughout
- [ ] Check for synchronization issues
- [ ] Review color consistency
- [ ] Verify graphics/text readability

**Stakeholder Review** (if applicable)
- [ ] Share rough cut with key stakeholders
- [ ] Gather feedback on:
  - [ ] Content accuracy
  - [ ] Message clarity
  - [ ] Overall tone/style
  - [ ] Any misleading information
- [ ] Document all feedback
- [ ] Prioritize feedback (what to change vs. nice-to-have)
- [ ] Make essential corrections

**Revision**
- [ ] Make requested revisions
- [ ] Re-order sections if feedback suggests
- [ ] Remove or expand sections as needed
- [ ] Re-cut for better pacing
- [ ] Export updated rough cut
- [ ] Review revisions
- [ ] Get approval for final edits

### 3.7 Final Editing & Polishing

**Final Review & Corrections**
- [ ] Complete final pass through entire video
- [ ] Fix any remaining issues
- [ ] Double-check all facts/information
- [ ] Verify all links are mentioned correctly
- [ ] Check for any visual glitches
- [ ] Check audio levels one more time
- [ ] Verify color consistency
- [ ] Check temporal sync between audio and video
- [ ] Optimize file size if needed
- [ ] Verify duration is within target

**Final Details**
- [ ] Ensure intro is engaging
- [ ] Ensure outro call-to-action is clear
- [ ] Verify captions are complete and accurate
- [ ] Verify graphics are professional
- [ ] Check that video tells cohesive story
- [ ] Verify content value is clear
- [ ] Test video on different devices/sizes
- [ ] Final approval

## PHASE 4: EXPORT & DELIVERY

### 4.1 Export Settings

**Video Export Specifications**
- [ ] Resolution: 1920x1080 (1080p)
- [ ] Frame rate: 23.976 fps (24p) or 29.97 fps (30p)
- [ ] Codec: H.264 (H.265 if platform supports)
- [ ] Bitrate: 5000-8000 kbps (YouTube-friendly)
- [ ] Color space: rec709 / sRGB
- [ ] Container: MP4 (.mp4 file)
- [ ] Field order: Progressive (not interlaced)
- [ ] Verify export settings in software

**Audio Export Specifications**
- [ ] Format: AAC or MP3
- [ ] Bitrate: 128-192 kbps
- [ ] Sample rate: 48 kHz
- [ ] Channels: Stereo
- [ ] Normalize: -3dB peak, -18dB average
- [ ] Verify export settings

**Subtitle/Caption Export**
- [ ] Export captions in SRT format
- [ ] Verify SRT formatting is correct
- [ ] Test that timecodes are accurate
- [ ] Create separate captions file
- [ ] Name file clearly (videotitle-captions.srt)

### 4.2 Quality Assurance

**Playback Quality Check**
- [ ] Play exported file in media player
- [ ] Verify video quality is good
- [ ] Verify audio quality is good
- [ ] Check that entire video plays without errors
- [ ] Verify there's no stuttering or glitching
- [ ] Check that duration is correct
- [ ] Verify color looks good
- [ ] Listen for audio issues (hum, distortion)
- [ ] Test on different playback devices

**File Integrity Check**
- [ ] Verify file size is reasonable
- [ ] Verify file is complete (not corrupted)
- [ ] Test on second device to verify compatibility
- [ ] Create backup of final export
- [ ] Verify backup is playable
- [ ] Create second backup on separate storage

**Metadata Verification**
- [ ] Verify file name is clear and follows naming convention
- [ ] Add file metadata (title, description, keywords)
- [ ] Verify metadata in file properties
- [ ] Document all metadata for records

## PHASE 5: UPLOADING & OPTIMIZATION

### 5.1 Pre-Upload Preparation

**Platform Selection & Account**
- [ ] Verify YouTube account is active
- [ ] Verify account has no restrictions
- [ ] Check channel settings are correct
- [ ] Verify channel art and description current
- [ ] Check channel is not pending verification
- [ ] Verify upload limits are not exceeded

**Metadata Preparation**
- [ ] Create optimized title (40-60 chars visible)
- [ ] Write compelling description (250-300+ words)
- [ ] Include hook in first 100 characters
- [ ] Add timestamps/chapters to description
- [ ] Include 5-10 relevant resource links
- [ ] Write 5-10 relevant tags
- [ ] Prepare thumbnail image (1280x720px)
- [ ] Review thumbnail readability at small size
- [ ] Prepare custom thumbnail (vs auto)
- [ ] Write call-to-action text
- [ ] Plan suggested next videos

**Thumbnail & Graphics Preparation**
- [ ] Design custom thumbnail (high contrast)
- [ ] Verify thumbnail text is readable at 168x94px
- [ ] Verify thumbnail doesn't mislead
- [ ] Verify thumbnail matches title
- [ ] Export thumbnail as JPG or PNG
- [ ] Verify file size under 2MB
- [ ] Create backup thumbnail design
- [ ] A/B test thumbnail variations planned

### 5.2 Upload Process

**YouTube Upload**
- [ ] Go to YouTube Studio
- [ ] Click "Create" > "Upload Video"
- [ ] Select video file
- [ ] Monitor upload progress
- [ ] Wait for upload to complete before closing
- [ ] Video processing begins automatically
- [ ] Video is now unlisted/draft by default

**Metadata Entry**
- [ ] Enter optimized title
- [ ] Enter description with all sections
- [ ] Add chapters/timestamps to description
- [ ] Select primary category
- [ ] Verify visibility is set correctly:
  - [ ] Private (for final review)
  - [ ] Unlisted (for scheduled release)
  - [ ] Public (for immediate release)
- [ ] Add playback rights (if applicable)
- [ ] Enable automatic captions
- [ ] Verify automatic captions are generally accurate

**Thumbnail Upload**
- [ ] Upload custom thumbnail image
- [ ] Verify thumbnail appears correctly
- [ ] Verify aspect ratio is not stretched
- [ ] Compare to auto-generated thumbnail

**Tags & Categories**
- [ ] Add 5-10 relevant tags
- [ ] Verify tags are relevant (not spam)
- [ ] Select primary category
- [ ] Verify category matches content
- [ ] Select content rating (usually appropriate for all ages)
- [ ] Enable/disable comments as appropriate
- [ ] Enable/disable ratings display
- [ ] Enable/disable suggestions of similar videos

### 5.3 Caption & Subtitle Upload

**Upload Captions**
- [ ] Go to Subtitles section
- [ ] Click "Add Language" > English
- [ ] Upload SRT file with captions
- [ ] YouTube auto-detects timing
- [ ] Review captions for accuracy
- [ ] Edit any incorrect captions
- [ ] Verify captions display correctly
- [ ] Make captions public (viewers can see)
- [ ] Publish captions

**Add Translations** (if applicable)
- [ ] Add captions in additional languages
- [ ] Use professional translation service
- [ ] Verify translations are accurate
- [ ] Publish translations

### 5.4 Video Details & Advanced Settings

**Details Section**
- [ ] License: Set to Creative Commons (if appropriate)
- [ ] Recording date: Enter actual recording date
- [ ] Recording location: Enter if relevant
- [ ] Language: Select English (or appropriate language)
- [ ] Captions certification: Mark captions as professional

**Advanced Settings**
- [ ] Allow embedding: Enable (usually)
- [ ] Content rating: Select appropriate rating
- [ ] Video language: Set to English
- [ ] Enable YouTube's automated caption generation
- [ ] Set video as made-for-kids (if applicable)
- [ ] Verify all settings are appropriate

**Monetization** (if applicable)
- [ ] Check monetization is enabled (if eligible)
- [ ] Verify no copyright claims on music
- [ ] Verify all music/footage is properly licensed
- [ ] Check for any demonetization flags
- [ ] Accept advertiser-friendly content guidelines

**Playlists**
- [ ] Add video to relevant playlists
- [ ] Create new playlist if part of series
- [ ] Verify playlist order is logical
- [ ] Update playlist descriptions
- [ ] Update playlist thumbnails

### 5.5 Schedule & Publishing

**Schedule vs. Publish**
- [ ] Decide publish timing strategy:
  - [ ] Publish immediately

## COMMON PRODUCTION ISSUES & SOLUTIONS

| Issue | Cause | Solution |
|-------|-------|----------|
| Poor audio quality | Bad microphone placement | Reposition mic 6-12" from mouth, off-axis |
| Hum in audio | AC power interference | Use balanced XLR cables, move away from power |
| Video codec errors | Incompatible codec | Export in H.264, check YouTube spec |
| Color inconsistency | Different lighting | Normalize color in post, use same lights |
| Stuttering video | Low bitrate | Increase bitrate to 8000+ kbps |
| Echo in audio | Bad room acoustics | Add soft materials (blankets, foam) to room |
| Sync issues | Mismatch in frame rates | Match editing timeline frame rate to source |
| Slow exports | High-quality rendering | Reduce export bitrate, use proxy editing |
| Playback issues | Corrupted file | Re-export from original files |
| Metadata errors | Typos in description | Proofread before publishing, fix after |
