## Screen Recording Best Practices

### Setup
```markdown
1. **Resolution**: Record at 1920x1080 or 2560x1440
2. **Font Size**: Increase terminal/editor font (16-20pt)
3. **Color Scheme**: High contrast, readable colors
4. **Window Size**: Maximize or use consistent window size
5. **Distractions**: Hide notifications, close unnecessary apps
```

### During Recording
```markdown
1. **Pace**: Speak clearly, not too fast
2. **Mouse**: Move deliberately, highlight clicks
3. **Pauses**: Leave brief pauses for editing
4. **Mistakes**: Keep recording, fix in editing
5. **Energy**: Maintain enthusiastic but professional tone
```

### Captioning and Accessibility

**Captioning Standards**

Professional captioning requires:
- [ ] 99%+ accuracy
- [ ] Proper punctuation
- [ ] Speaker identification
- [ ] Sound effects noted [music], [applause]
- [ ] Proper spacing (2-3 seconds per caption)
- [ ] Max 2 lines per caption
- [ ] Synced within 0.5 seconds

**Caption Format (WebVTT)**

```
WEBVTT

00:00:00.000 --> 00:00:03.000
Welcome to building your first REST API.

00:00:03.500 --> 00:00:07.000
Today we're using Express.js and PostgreSQL
to create a production-ready application.
```

**Captions vs Subtitles**

- **Captions**: Include all audio (dialogue, sound effects, music cues)
- **Subtitles**: Just dialogue, assumes hearing audio
- **Always provide captions**: Accessibility + searchable

**Creating Captions**

1. **Rev.com**: Professional service ($1.25/min)
2. **Otter.ai**: AI transcription + manual review
3. **YouTube**: Auto-captions (then manually correct)
4. **Manual**: Edit .vtt file directly (tedious but accurate)

### Video Hosting Options

**YouTube** (Free, public)
- **Pros**: Free, largest platform, excellent discoverability, built-in analytics
- **Cons**: Ads (unless monetized), less control, index may vary
- **Best for**: Public tutorials, community learning

**Vimeo** (Paid, private)
- **Pros**: Beautiful player, private control, better for professionals, no ads
- **Cons**: Cost ($75+/month), smaller audience
- **Best for**: Paid courses, client work, high-end content

**Wistia** (Paid, private)
- **Pros**: Advanced analytics, private, embedded player, heatmaps
- **Cons**: Cost ($99+/month), smaller platform
- **Best for**: Sales videos, training, marketing metrics

**Mux** (Developer-first)
- **Pros**: API-first, excellent performance, great for embedded videos
- **Cons**: Cost-based on usage, more technical
- **Best for**: Embedded in documentation, custom players

### Video Analytics and Metrics

**Key Metrics to Track**

- **Views**: Total video views
- **Watch time**: Total minutes watched
- **Average view duration**: How much people watch
- **Click-through rate**: Clicks on links in description
- **Engagement**: Comments, likes, shares
- **Traffic source**: Where viewers come from
- **Device**: Mobile, desktop, tablet

**Using Analytics**

```
IF watch time is low → Content is boring, trim length
IF click-through is low → Call-to-action unclear
IF most viewers drop at same point → Content is confusing there
IF mobile viewers are lower → Content not mobile-friendly
```
