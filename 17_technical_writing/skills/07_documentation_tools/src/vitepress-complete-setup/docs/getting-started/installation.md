# Installation

Install Project and get started with our platform.

## System Requirements

- Node.js 18+
- npm or yarn
- 2GB RAM
- 500MB disk space

## NPM Installation

```bash
npm install @project/sdk
```

## Python Installation

```bash
pip install project-sdk
```

## Docker

```bash
docker run -it project/sdk:latest
```

## Verify Installation

```javascript
import Project from '@project/sdk'
console.log(Project.version)
// Output: 1.0.0
```
