# Test: Inclusive Language Standards

## Purpose

Ensure documentation uses inclusive, non-discriminatory language.

## Passing Examples

### Technology Terminology

Use an allowlist to specify trusted domains in your configuration.

Create a blocklist for IP addresses you want to reject.

Configure the primary database with a replica for failover.

The personnel were trained on the new procedures.

### Gender-Neutral Language

The developer should review their code before submitting.

Each team member can configure their own preferences.

Users can update their profile information.

The person responsible for this task will contact you.

### Accessible Language

The development of this feature has some limitations.

The API has unresponsive endpoints under load.

This configuration approach has a few constraints.

### Culturally Sensitive

We use best-in-class practices for our implementation.

The system has powerful features for advanced users.

This implementation approach is unusual but effective.

### Professional Inclusivity

Our workplace includes people of all backgrounds and experiences.

We welcome developers at all career stages.

Team members bring different perspectives to problem-solving.

## Failing Examples

### Outdated Technology Terms

Add the whitelist to your security configuration.

The blacklist prevents those domains from accessing our service.

The master database replicates to the slave node.

We need more manpower to complete this project.

### Non-Inclusive Language

The guys reviewed the code yesterday.

He should configure his settings.

She will manage the team.

The developer should update his code.

### Ableist Language

This code is crazy complex.

The API behavior is insane.

The system acts like a schizophrenic application.

This approach is lame compared to alternatives.

### Outdated Metaphors

We're suffering from database performance issues.

The legacy system is completely crippled.

Network connectivity is deaf to requests.

### Unnecessarily Gendered Roles

The businessman negotiated the contract.

The stewardess assisted passengers.

The chairman called the meeting to order.

The fireman extinguished the blaze.

## Notes

Inclusive language practices:

- Use gender-neutral pronouns (they/them)
- Replace problematic technical terms
- Avoid ableist expressions
- Use role-based descriptions
- Respect diverse perspectives
- Recognize different abilities and backgrounds

## Terminology Replacements

| Avoid | Use Instead |
|-------|------------|
| whitelist | allowlist |
| blacklist | blocklist |
| master | primary |
| slave | replica |
| manpower | personnel |
| guys | team/folks/people |
| he/she | they |
| crazy/insane | complex/unusual |
| suffers from | lives with |
| crippled | limited |
