## Section 1: Fundamentals & Principles (10 questions)

### Question 1.1
**Type**: Multiple Choice
**Weight**: 3%

What is the primary purpose of a tutorial?

A) To provide comprehensive reference material
B) To guide learners through practical steps to achieve a specific goal
C) To document all features of a system
D) To serve as legal documentation

**Correct Answer**: B
**Explanation**: Tutorials are task-oriented guides designed to help learners accomplish specific goals through step-by-step instruction.

---

### Question 1.2
**Type**: True/False
**Weight**: 2%

A tutorial should include comprehensive reference documentation for every feature mentioned.

**Correct Answer**: False
**Explanation**: Tutorials focus on essential information needed for the task. Comprehensive reference material belongs in separate documentation.

---

### Question 1.3
**Type**: Multiple Choice
**Weight**: 3%

Which of the following best describes the tutorial's target audience?

A) Advanced developers familiar with the system
B) Users attempting specific, practical tasks
C) System administrators only
D) Documentation maintainers

**Correct Answer**: B
**Explanation**: Tutorials target users trying to accomplish specific tasks, regardless of their experience level.

---

### Question 1.4
**Type**: Multiple Choice
**Weight**: 2%

What should a tutorial avoid?

A) Clear, simple language
B) Step-by-step instructions
C) Assuming unnecessary prior knowledge
D) Real-world examples

**Correct Answer**: C
**Explanation**: Tutorials should minimize assumed knowledge and explain concepts clearly for learners.

---

### Question 1.5
**Type**: True/False
**Weight**: 2%

The term "scaffolding" in tutorial design refers to providing support structures that gradually decrease as learner competence increases.

**Correct Answer**: True
**Explanation**: Scaffolding is an educational technique where support is provided initially and gradually reduced.

---

### Question 1.6
**Type**: Multiple Choice
**Weight**: 3%

Which principle is most important for tutorial success?

A) Covering all possible topics
B) Using technical jargon to establish authority
C) Ensuring learners achieve the stated goal
D) Providing exhaustive explanation of theory

**Correct Answer**: C
**Explanation**: A successful tutorial enables learners to accomplish the specific goal efficiently.

---

### Question 1.7
**Type**: True/False
**Weight**: 2%

Tutorials should be independent and not rely on readers having completed other tutorials.

**Correct Answer**: False
**Explanation**: Tutorials can build on previous knowledge, but should clearly state prerequisites.

---

### Question 1.8
**Type**: Multiple Choice
**Weight**: 2%

What is the ideal length for a beginner tutorial?

A) 5-10 minutes
B) 30-60 minutes
C) 2-3 hours
D) Full working day

**Correct Answer**: B
**Explanation**: Beginner tutorials typically take 30-60 minutes, balancing comprehensiveness with user engagement.

---

### Question 1.9
**Type**: True/False
**Weight**: 3%

In tutorial writing, active voice (e.g., "You will create") is preferred over passive voice (e.g., "A file will be created").

**Correct Answer**: True
**Explanation**: Active voice directly addresses the reader and provides clearer instructions.

---

### Question 1.10
**Type**: Multiple Choice
**Weight**: 2%

What is the primary difference between a tutorial and a guide?

A) Length only
B) Tutorials are task-specific; guides are broader reference materials
C) Guides are always longer
D) Tutorials use different technology

**Correct Answer**: B
**Explanation**: Tutorials focus on specific tasks; guides provide broader information for reference.

A) Complete feature documentation
B) Overview of what will be learned, expected duration, and prerequisites

---

### Question 2.2
**Type**: True/False
**Weight**: 2%

**Correct Answer**: True
**Explanation**: Proper heading hierarchy helps readers navigate and understand information organization.

---

### Question 2.3
**Type**: Multiple Choice
**Weight**: 2%

What is the correct order for tutorial sections?

A) Conclusion, steps, introduction, setup
B) Introduction, setup, steps, conclusion
C) Setup, introduction, conclusion, steps

**Correct Answer**: B
**Explanation**: Introduction → Setup → Steps → Conclusion is the logical flow.

### Question 2.4
**Type**: True/False
**Weight**: 3%

Numbered lists should be used for sequential steps, while bullet points suit optional or unordered information.

**Correct Answer**: True
**Explanation**: Numbering indicates sequence and progress; bullets indicate non-sequential items.

### Question 2.6
