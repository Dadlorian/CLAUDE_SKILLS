# Project Assessment Rubric

Comprehensive rubric for evaluating final tutorial writing projects. Designed for capstone or culminating assignments.

---

## Scoring Scale

**4 - Exemplary**: Exceeds expectations; publishable quality
**3 - Proficient**: Meets expectations; competent execution
**2 - Developing**: Partially meets expectations; revision needed
**1 - Beginning**: Does not meet expectations; major gaps
**0 - Missing**: Not attempted or fundamentally absent

---

## Scoring Calculation

### Step 1: Calculate Dimension Averages
Average scores for subcategories within each dimension.

### Step 2: Calculate Weighted Total
```
Total = Σ(Dimension Average × Weight)

Example:
Planning: 3.5 × 0.15 = 0.525
Audience: 3.5 × 0.15 = 0.525
Content: 3.0 × 0.20 = 0.600
Hands-On: 3.5 × 0.15 = 0.525
Technical: 3.0 × 0.12 = 0.360
Assessment: 3.5 × 0.12 = 0.420
Documentation: 3.5 × 0.11 = 0.385
Reflection: 3.0 × 0.10 = 0.300

Total: 3.64 ÷ 4.0 = 0.91 = 91%
```

### Step 3: Convert to Percentage
```
Percentage = (Total / 4.0) × 100
Example: (3.64 / 4.0) × 100 = 91%
```

## Calibration for Consistency

When multiple evaluators score:

1. **Discuss Standards**: Align on what exemplary work looks like
2. **Score Sample**: All score same project independently
3. **Compare & Discuss**: Discuss differences and align understanding
4. **Re-score**: Score additional projects with aligned standards
5. **Monitor**: Spot-check consistency throughout evaluation period

---

## Grade Appeal Process

Students may appeal if they believe:
- Rubric was not fairly applied
- Scoring is inconsistent with examples
- Technical issues prevented full evaluation
- Evaluation based on incorrect information

**Process**:
1. Student submits appeal with specific rubric dimension
2. Evaluator reviews and provides detailed response
3. If needed, secondary evaluator reviews
4. Final decision documented
