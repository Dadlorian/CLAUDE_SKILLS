# Assessment Rubrics - Tutorial Writing Skills

Comprehensive grading and assessment rubrics for evaluating tutorial writing projects, hands-on labs, and certification exams.

---

## Contents

### 1. Tutorial Quality Rubric
**File**: `tutorial-quality-rubric.md`

Assess overall tutorial quality across seven dimensions:
- **Learning Objectives** (15%): Clarity and prerequisite alignment
- **Content Quality** (20%): Accuracy, completeness, currency
- **Structure & Organization** (15%): Flow, chunking, navigation
- **Audience Appropriateness** (12%): Language, engagement, inclusivity
- **Hands-On Elements** (12%): Code examples, interactive features
- **Troubleshooting & Support** (8%): Help resources and error handling
- **Technical Presentation** (6%): Accessibility and media quality

**Use Cases**:
- Evaluating tutorial manuscripts before publication
- Quality assurance during content review
- Assessing improvements in existing tutorials
- Training new technical writers on quality standards

**Scoring**: 0-4 scale per dimension, weighted calculation to 0-100%

### 2. Hands-On Lab Assessment Rubric
**File**: `hands-on-lab-rubric.md`

Evaluate student performance in lab assignments across five categories:
- **Technical Implementation** (30%): Functionality, code quality, error handling
- **Testing & Verification** (20%): Test coverage, validation methods
- **Problem-Solving & Debugging** (15%): Analysis approach, troubleshooting
- **Documentation & Communication** (15%): Code docs, README, reflection
- **Version Control & Collaboration** (10%): Git usage, team interaction

**Use Cases**:
- Grading hands-on lab submissions
- Assessing coding assignment quality
- Identifying student strengths and development areas
- Providing constructive feedback on technical work

**Scoring**: 0-4 scale per criterion, weighted total to percentage

**Grade Scale**:
- A (90-100%): Exemplary
- B (80-89%): Proficient
- C (70-79%): Developing
- D (60-69%): Beginning
- F (<60%): Unsatisfactory

### 3. Project Assessment Rubric
**File**: `project-assessment-rubric.md`

Comprehensive evaluation of capstone/final tutorial writing projects across eight dimensions:
- **Project Planning & Scope** (15%): Strategic planning, scope definition
- **Target Audience Understanding** (15%): Research, personas, accessibility
- **Content Development** (20%): Quality, objectives alignment, organization
- **Hands-On & Practical Elements** (15%): Exercises, code samples, verification
- **Technical Excellence** (12%): Accessibility, performance, maintenance
- **Assessment & Quality Assurance** (12%): Assessment strategy, testing, support
- **Documentation & Deliverables** (11%): Project docs, completeness, version control
- **Reflection & Professional Growth** (10%): Learning reflection, development

**Use Cases**:
- Final project/capstone evaluation
- Comprehensive portfolio assessment
- Career readiness evaluation
- Evidence of professional competency

**Scoring**: 0-4 scale, weighted calculation to percentage

**Grade Scale**:
- A+ (95-100%): Exceptional; publishable
- A (90-94%): Excellent
- B+ (85-89%): Very Good
- B (80-84%): Good
- C+ (75-79%): Satisfactory
- C (70-74%): Adequate
- F (<70%): Unsatisfactory

## How to Use the Rubrics

### Before Grading

1. **Read Thoroughly**: Review the entire rubric
2. **Understand Standards**: Study the "Exemplary" (4) descriptions
3. **Calibrate**: If working with others, discuss what exemplary looks like
4. **Gather Evidence**: Collect work samples if available

### During Grading

1. **Score Holistically First**: Get an overall sense of quality
2. **Score Each Dimension**: Use specific descriptions and examples
3. **Document Evidence**: Note specific strengths and areas for improvement
4. **Be Consistent**: Apply same standards throughout
5. **Take Notes**: Record specific examples for feedback

### After Grading

1. **Calculate Scores**: Use weighted formulas provided
2. **Write Feedback**: Be specific, constructive, and actionable
3. **Provide Resources**: Suggest how to improve
4. **Consider Calibration**: Compare with peers if possible

## Weighted Calculations

### Tutorial Quality Rubric Example

```
Learning Objectives:     3.5 × 0.15 = 0.525
Content Quality:          3.0 × 0.20 = 0.600
Structure:                4.0 × 0.15 = 0.600
Audience:                 3.5 × 0.12 = 0.420
Hands-On:                 3.0 × 0.12 = 0.360
Troubleshooting:          3.5 × 0.08 = 0.280
Technical:                3.5 × 0.06 = 0.210
                                        ─────
Total:                                 2.995

Percentage: (2.995 / 4.0) × 100 = 74.9% ≈ 75% (C)
```

## Feedback Best Practices

### Effective Feedback Characteristics

✓ **Specific**: Reference exact sections with line numbers or examples
✓ **Actionable**: Suggest concrete improvements
✓ **Balanced**: Include strengths alongside areas for growth
✓ **Growth-Minded**: Frame as development opportunities, not failures
✓ **Timely**: Provide soon after assessment
✓ **Documented**: Share in writing for reference

### Poor Feedback Examples to Avoid

✗ "Good job" (vague)
✗ "This is bad" (harsh, unhelpful)
✗ "Fix this" (no guidance)
✗ Only listing weaknesses (demoralizing)
✗ Generic comments (not specific)

### Strong Feedback Examples

✓ "The learning objectives in Section 2 are clearly stated with measurable action verbs. To improve further, ensure the prerequisites section explains WHY each prerequisite matters."

✓ "Your code examples are functional and demonstrate the concepts well. To exemplary level, add explanatory comments above each code block showing what the code does before readers see it."

✓ "The troubleshooting section addresses 3 common issues. Consider expanding to 5-7 issues based on user feedback patterns you mentioned in your planning."

## Rubric Adaptation

### For Different Contexts

#### University Courses
- May weight reflection/learning more heavily
- Emphasize academic integrity
- Focus on growth and improvement
- Provide extensive feedback

#### Professional Organizations
- May weight technical accuracy more
- Emphasis on publication readiness
- Focus on standards compliance
- Faster feedback cycles

#### Self-Assessment
- Use as learning tool, not just grading
- Identify personal development areas
- Track improvement over time
- Compare against exemplary models

### Customization Tips

1. **Adjust Weights**: Emphasize most important dimensions
2. **Add Criteria**: Include context-specific requirements
3. **Modify Scale**: Use 1-3 or 1-5 if preferred
4. **Add Levels**: Insert intermediate levels (3.5, 2.5) if needed
5. **Create Variants**: Different rubrics for different tutorial types

## Consistency & Calibration

### Multi-Rater Calibration

When multiple people grade using the same rubric:

1. **Initial Meeting** (30 min)
   - Read rubric together
   - Discuss what exemplary looks like
   - Share expectations

2. **Practice Round** (30-45 min)
   - All grade same sample
   - Compare scores
   - Discuss differences

3. **Aligned Grading** (ongoing)
   - Grade independently
   - Spot-check for consistency
   - Recalibrate as needed

### Tracking Consistency

Maintain records of:
- Average scores per rubric dimension
- Score distribution (how many As, Bs, Cs, etc.)
- Rater agreement percentage
- Outlier scores and reasons

**Target**: 90%+ score agreement within one point difference

## Grade Appeal & Review

### Appeal Process

1. **Student Request**: Within 5 business days of grade
2. **Provide Evidence**: Specific rubric dimension and reasoning
3. **Evaluator Review**: Reconsider score with evidence
4. **Second Reviewer**: If substantial disagreement
5. **Final Decision**: Documented in writing

### Grounds for Appeal

✓ Rubric not fairly applied
✓ Scoring inconsistent with rubric level
✓ Technical issue prevented full evaluation
✓ Grading based on incorrect information

✗ Simple disagreement with grade
✗ Difficulty of assignment
✗ Impact on GPA or progression
